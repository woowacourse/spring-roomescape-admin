
## 학습법 v1
1. 개념 이해
   코드로 들어가기 전, 모르는 개념이 있다면 먼저 AI를 통해 추상적인 정보를 구체화한다. 이후 공식 문서를 우선적으로 읽고, 블로그를 통해 실제 사례와 해석을 비교하며 이해를 넓힌다.
2. 코드 적용
   정리한 개념을 직접 코드에 적용하고 실행해보며 실제 동작을 확인한다. 단순한 따라 치기가 아니라 개념과 연결해서 이해하려고 한다. 
3. 검증
   작성한 코드와 이해한 방식이 맞는지 AI, 공식 문서, 블로그를 통해 다시 교차 검증한다. 이 과정에서 잘못 이해한 부분을 수정하고 더 정확한 기준을 만든다. 
4. 추가 탐색
   코드를 적용한 이후 새롭게 생긴 궁금증이나 더 깊게 알고 싶은 부분을 추가로 학습한다. 처음부터 모든 것을 공부하기보다 필요가 생겼을 때 확장하는 방식이다.
