# 🕹️ 방탈출 예약 관리 웹 애플리케이션

방탈출 예약 관리를 위한 웹 애플리케이션입니다.  
관리자는 시간대를 설정하고, 고객은 해당 시간에 맞춰 예약할 수 있습니다.

---

## 🔗 접속 방법

| 페이지 이름 | 주소 | 설명 |
|------------|------|------|
| 관리자 홈 | `localhost:8080/admin` | 관리자 홈 화면 |
| 예약 관리 | `localhost:8080/admin/reservation` | 등록된 예약 확인 및 삭제 |
| 시간 관리 | `localhost:8080/admin/time` | 예약 가능한 시간대 등록/관리 |

---

## 🗃️ 데이터베이스 정보

- **H2 인메모리 데이터베이스 사용**
- 웹 콘솔 접속 주소: [http://localhost:8080/h2-console](http://localhost:8080/h2-console)

### 접속 정보
- **JDBC URL**: `jdbc:h2:mem:database`
- **User Name**: `sa`

---

## 🧭 사용 방법

1. **시간 등록**
    - `/admin/time` 페이지에서 예약 가능한 시간을 등록합니다.
2. **예약 관리**
    - `/admin/reservation` 페이지에서 예약을 등록하거나 삭제할 수 있습니다.

---

| 단계 | 내용 | 완료 여부 |
