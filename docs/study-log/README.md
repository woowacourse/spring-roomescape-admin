## 학습법 변천사
<br><br>

### 학습법 v1
<hr>
레벨1에서는 모르는 개념을 깊이 이해하는 데 집중하는 방식으로 학습했다.

하나의 개념을 학습하다가 새로운 개념이 등장하면, 해당 개념을 다시 파고드는 식으로 이해가 될 때까지 그 과정을 반복했다.
이 과정에서 개념 간 연결을 이해할 수 있다는 장점이 있었지만, 학습 범위가 계속 넓어지면서 전체적인 속도는 다소 느려졌던 것 같다.

또한 학습한 내용을 정리하는 데는 시간을 썼지만, 이후에 다시 돌아보며 복기하는 과정은 충분히 가져가지 못했다.

미션을 진행할 때는 설계보다는 빠르게 구현을 시작하고, 이후에 구조를 돌아보는 방식을 선택했다.
미션 진행 후 리뷰를 받고 나서는 각 리뷰에 대해 리뷰어는 왜 이런 리뷰를 남겼을지를 스스로 고민하며 의도를 해석하려고 했다.
추가로, 혼자 해결하기 어려운 문제나 토론이 필요한 주제가 생기면 크루들에게 물어보면서 다양한 생각을 들어보았다.

<br><br>

### 학습법 v2
<hr>

한 번에 하나의 개념에만 집중하여 학습하는 것을 원칙으로 삼는다.
여러 개념을 동시에 다루기보다는, 지금 이해하려는 하나의 개념에 몰입함으로써 개념 간 혼동을 줄이고 본질을 더 깊이 파악할 수 있도록 한다.
학습 도중 새로운 개념이 등장하더라도 흐름을 끊지 않는 것을 우선으로 한다.
지금 다루고 있는 핵심 개념의 이해를 방해하지 않는 선에서 해당 개념을 가볍게 파악하고,
필요한 최소한의 수준으로만 익힌 뒤 다시 현재의 학습으로 돌아온다.
또한 학습한 내용을 단순히 한 번 이해하는 데 그치지 않고, 기억에 오래 남을 수 있도록 정리하고 반복적으로 복습하는 과정을 가진다.

<br><br>

### 학습법 v3
<hr>

#### **[코어 루프: 재구성(Reconstruction) 프로세스]**

학습의 목적은 요약 정리가 아니라, 외부 도움 없이 개념을 **무(無)에서 유(有)로 설계**할 수 있는 상태를 만드는 것

**STEP 01. 입력 (Input):** 개념의 원리를 파악하고 학습한다.

**STEP 02. 차단 (Blackout):** 모든 자료를 닫고 스스로 학습한 내용을 설명한다.

**STEP 03. 인출 (Retrieval):** 아래 4가지 본질적 질문에 스스로 답하며 개념을 나만의 언어로 다시 설계한다.

1. **Why:** 이 기술은 왜 탄생했는가? (필연성)
2. **Problem:** 어떤 문제를 해결해주는가? (해결책)
3. **Edge Case:** 사용하지 않았을 때 어떤 한계점이 발생하는가? (한계점)
4. **Contrast:** 유사 기술과의 결정적 차이는 무엇인가? (차별성)

**STEP 04. 동기화 (Sync):** 원본과 비교하여 누락된 내용을 보완한다.

<br>

#### **[가속 전략: 인지 최적화를 위한 3가지 장치]**

- **Interleaving (맥락 교차) :** 유사하거나 상반된 개념(예: 트랜잭션 vs 인덱스)을 번갈아 배치한다.
- **Constraint (강한 제약) :** 당연하게 쓰던 프레임워크나 라이브러리를 제거하고 생각한다.
- **Prediction (가설 검증) :** 실행 결과나 정답을 보기 전, 나만의 논리로 결과를 먼저 예측한다.
