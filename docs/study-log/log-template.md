### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
이번 전략은 AI를 이용해서 핵심 키워드에 대해 얕게 학습하는 것이었다. 아직 사이클을 전부 돌지 않았기 때문에 궁금증이 생기는 부분만 해결했다.

- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
@RestController, @Bean와 같은 어노테이션이 어떤 역할을 하는지 명확히 알지는 못한채로, 사용해왔다.
이번에는 어떤 기능을 하는지 알아보려고 한다.

- `@RestController에 대한 지식이 필요해 공식문서만을 참고해서 나의 학습을 도와줘. 이때 정답을 알려주지 말고 질문을 통해서 나의 성장을 이끌어줘`

이 과정에서 바뀐 지점에 대해 작성하겠다.

1. @Controller
이전: @Controller는 웹 Api 통신을 하는 Controller 임을 명시하는 어노테이션이야. 어떤 역할을 하는지는 모르겠어.
이후: Http 요청을 받는 역할이고, 데이터를 변환하는 역할은 다른 곳에서 실행된다. -> 데이터와 표현을 분리한다.

2. @ResponseBody
이전: @ResponseBody는 문자 그대로 웹으로 보내주는 역할을 한다, 어노테이션이 없다면 hello라는 뷰이름을 검색해서 전달하게 된다.
이후: @ResponseBody는 Controller의 반환값(객체)을 Http의 응답 body로 변환하며, 이때 클라이언트의 요청을 고려한다. 반환 타입이 없다면 에러를 리턴한다.
