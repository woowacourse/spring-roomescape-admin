# 방탈출 예약 관리

## API 명세
**페이지 API**

|    기능    | HTTP Method |         URL         |
|:--------:|:-----------:|:-------------------:|
|   홈 화면   |     GET     |          /          |
|  관리자 화면  |     GET     |       /admin        |
| 예약 관리 화면 |     GET     | /admin/reservations |


**REST API**

|    기능    | HTTP Method |        URL         | Request Body                                             | Response Body                                                              |
|:--------:|:-----------:|:------------------:|----------------------------------------------------------|----------------------------------------------------------------------------|
|  예약 추가   |    POST     |   /reservations    | { "name": "Ken", "date": "2025-04-20", "time": "23:00" } | { "id": 1, "name": "Ken", "date": "2025-04-20", "time": "23:00" }          |
| 예약 목록 조회 |     GET     |   /reservations    | 없음                                                       | [ { "id": 1, "name": "Ken", "date": "2025-04-20", "time": "23:00" }, ... ] |
|  예약 취소   |   DELETE    | /reservations/{id} | 없음                                                       | 없음                                                                         |
