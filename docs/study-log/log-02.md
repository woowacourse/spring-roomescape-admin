### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
  - AI로 전체 구조를 훑은 뒤 직접 써보는 전략 + 학습법 적용
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.

AI 로 요구사항을 넣고 학습을 어떻게 할 지 도와달라는 프롬프트를 작성하였다.
추천하는 구현 순서, 구현 시 주의해야 할 포인트를 바탕으로 학습 전략을 세웠다.
```
1. 환경 설정: build.gradle과 application.properties를 수정하고 서버를 켜서 /h2-console에 접속되는지 확인하세요.
2. 조회(GET) API: 우선 schema.sql에 테스트 데이터를 INSERT 문으로 몇 개 넣어두고, 그걸 JdbcTemplate으로 읽어와서 화면(또는 테스트)에 뿌리는 것부터 시작하세요.
3. 삭제(DELETE) API: ID만 있으면 되므로 추가보다 구현이 쉽습니다.
4. 추가(POST) API: 마지막으로 KeyHolder를 이용해 데이터를 넣고 ID를 반환받는 로직을 완성하세요.

구현 시 주의해야 할 3가지 포인트
1. RowMapper: DB 행을 객체로 변환하기
2. KeyHolder: 새로 생성된 ID 가져오기
3. 데이터 타입의 불일치
```

이를 토대로 아래의 학습 순서로 진행하였다.
1. build.gradle에 어떤 dependencies를 추가해야 하고, application.properties를 수정하는 코드의 의미가 무엇인지 파악한다.
2. schema.sql에 기본 테이블 구조를 넣고 메모리에서 데이터베이스로 변경 시, 어떤 코드로 수정 해야하는지 학습한다.
3. RowMapper, KeyHolder, PreparedStatementCreator를 학습하고 코드에 적용할 수 있도록 학습한다.
4. 데이터 타입 불일치 학습하고 코드에 적용할 수 있도록 학습한다.

학습테스트로 spring-jdbc-1을 가지고 이전 1단계와 동일하게 학습법 v3를 사용하여 학습하였다.
