### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?

### 3. 전략 평가
- 효과적이었던 것과 그 이유
  - 처음 접하는 키워드를 작성해두고 ai를 통해 빠르게 이해한 후 코드 작성 후에 다시 학습하는 방법이 이전 단계에서 느꼈던 수박 겉핥기 느낌을 지워주는 역할을 했다.
- 비효과적이었던 것과 그 이유
  - 작성이 끝나고 메서드 혹은 코드를 지우고 다시 작성해보는 것. 마감 기한이 생긴 레벨 2부터는 생각보다 심리적인 압박감이 있어서 미션 진행 중에 시도하기에는 시간이 많이 부족할 것이라 느껴졌다. 마감 전에 우선 빠르게 미션을 완료한 후에 리뷰를 기다리며 해당 방법을 시도해보면 더 효과적일 것 같다고 느꼈다.
- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?
  - 코드 작성 후에도 다시 학습을 진행하니 이전보다 남는 게 많다고 느껴졌다. 또한 미션 진행 자체에도 흐름이 끊기지 않아서 궁합이 꽤 괜찮다고 느껴졌다.

### 4. AI 피드백
- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고,
  유용했던 제안 1가지 이상 기록
  - 슬롯 기반 리팩터링: "전체를 지우는 압박감 대신, '핵심 문법'만 구멍을 뚫으세요."
    - 메서드 전체를 지우는 것은 시간적·심리적 부담이 큽니다. 대신, 이번에 학습한 구체적인 문법 요소만 의도적으로 비워두고 다시 채워 넣는 방식입니다.
    - 실행 방법: JdbcTemplate을 활용해 코드를 완성했다면, queryForObject나 RowMapper 익명 객체(또는 람다) 부분만 주석 처리하고 다시 작성해 보세요.
