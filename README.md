# 방탈출 예약 관리

## API 명세
**Page API**

|     기능      | HTTP Method |         URL         |
|:-----------:|:-----------:|:-------------------:|
|    홈 화면     |     GET     |          /          |
|   관리자 화면    |     GET     |       /admin        |
|  예약 관리 화면   |     GET     | /admin/reservations |
| 예약 시간 관리 화면 |     GET     |     /admin/time     |


**REST API**

예약

|    기능    | HTTP Method |        URL         | Request Body                                         | Response Body                                                                                  |
|:--------:|:-----------:|:------------------:|------------------------------------------------------|------------------------------------------------------------------------------------------------|
|  예약 추가   |    POST     |   /reservations    | { "name": "Ken", "date": "2025-04-20", "timeId": 1 } | { "id": 1, "name": "Ken", "date": "2025-04-20", "time": {"id": 1, "startAt": "23:00"} }        |
| 예약 목록 조회 |     GET     |   /reservations    | 없음                                                   | [ { "id": 1, "name": "Ken", "date": "2025-04-20", "time": {"id": 1, "startAt": "23:00"}, ... ] |
|  예약 취소   |   DELETE    | /reservations/{id} | 없음                                                   | 없음                                                                                             |
   
예약 시간

|     기능      | HTTP Method |     URL     | Request Body          | Response Body                           |
|:-----------:|:-----------:|:-----------:|-----------------------|-----------------------------------------|
|  예약 시간 추가   |    POST     |   /times    | { "startAt": "10:00"} | { "id": 1, "startAt": "10:00"}          |
| 예약 시간 목록 조회 |     GET     |   /times    | 없음                    | [ { "id": 1, "startAt": "10:00"}, ... ] |
|  예약 시간 삭제   |   DELETE    | /times/{id} | 없음                    | 없음                                      |
