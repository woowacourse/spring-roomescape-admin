# 학습법 정리

## v1 학습법
1. 모르는 개념이나 문법이 등장하면 AI에게 물어본다.
   - 개념은 실생활로 비유하고 관련된 예제코드도 달라고 요청한다.
   - 문법은 관련된 예제코드를 달라고 요청한다.
2. 개념과 문법에 대하여 이해를 한 뒤 코드에 적용한다.
3. 설계를 하다가 트레이드오프 지점이 생겼을 경우
    - AI에게 best practice로 나아가기 위한 질문을 해달라고 요청한다.
4. 그렇게 학습한 내용을 선택미션이나 여유로운 시간에 책이나 기술블로그를 통해 다시 접하면서, 
AI를 통해 이해했던 내용들을 더 구조적으로 정리하면서 해당 개념들을 굳혀갑니다.
5. v1 방식의 문제점: 
   - 개념이나 문법을 그 때 당시에는 완벽히 이해했다 생각하고 코드에 적용 후 그냥 넘어가는데
   나중에 같은 문제가 발생했을 때 기억이 휘발되어 쉽게 적용하지 못하는 문제점
   - best practice로 나아가기 위한 질문을 많이 받았을 경우,
   해당 질문들을 따라가며 하나씩 탐색하다 보면 처음 해결하고자 했던 문제에서 벗어나 관련 개념을 확장적으로 탐색하는 흐름으로 전환되어
   본래의 해결하고 했던 문제가 흐릿해지는 문제점
   - AI의 답변을 기반으로 학습하다 보니 해당 내용이 정말 올바른지 검증할 수 없는 문제점

## v2 학습법
1. AI가 답변해준 내용을 바탕으로 빠르게 개념 이해
    - 질문을 커다란 추상적인 내용으로 적지말고, 최대한 작은 문제로 구체화해서 질문하기
    - 완벽히 이해하는 것에 매몰되지 않기 → 기억이 희미해졌을 경우 기록한 것을 보면 됨.
2. 바로 코드 적용
3. 배운 내용을 글로 기록
4. 여유가 되는 시간에 책이나 기술블로그로 배운 내용을 굳혀가기

## v3 학습법
1. AI가 답변해준 내용을 바탕으로 빠르게 개념 이해
2. 바로 코드 적용 (일부러 실패 포함)
3. 막혔던 점 or 실패 로그 기록
4. 3번에서 도출된 약점만 따로 집중 훈련 (i+1 원칙 적용)
   - 하나의 약점 시도해보기
5. 제약 조건 추가하여 재도전 (i+1 원칙 적용)
   - 하나의 제약 조건을 걸어 재구현
6. 다른 방식으로 구현 후 비교 (i+1 원칙 적용)
   - 하나의 다른 방식을 구현
7. 설명 + 코드로 재현 (인출 훈련)
8. 배운 내용을 글로 기록

AI가 준 내용이 신뢰성 있는 지 판단하는 기준은 AI가 준 내용이 코드로 구현이 되는지 확인

&rarr; 동작이 되면 pass

&rarr; 동작이 안 되면 설명이 잘못된 것
