### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략
    - 검색 엔진을 사용하지 않고, AI만을 활용해서 개념 학습을 진행한다.
    - 학습을 시작하기 전에 "이 학습이 끝났다고 판단할 기준"을 먼저 정한다.
    - 학습 시작 전, "이 학습의 완료 조건: 막힌 부분의 코드를 한 줄이라도 쓸 수 있다"를 먼저 생각해라.
    - AI에게 묻기 전, 내가 이미 아는 것과 모르는 것의 경계를 검토한다.
    - 꼬리 질문이 생겼을 때 이렇게 자문한다. "이걸 몰라도 지금 당장 코드를 한 줄이라도 쓸 수 있는가?" 쓸 수 있으면 꼬리 질문을 메모만 하고 멈춘다. 쓸 수 없으면 그것이 다음 질문이 된다.
    - 개념을 먼저 배우고 코드를 짜는 것이 아니라, 코드를 먼저 짜다가 막히는 지점에서만 AI에게 묻는다.
- 실제 학습 과정
    1. 우선 미션 진행이 가능한 부분에 대해서는 진행을 한다.
    2. 미션을 진행하다가 헷갈리거나 궁금해서 막히는 부분이 생기면 노션에 질문을 작성한 다음, 아는 것과 모르는 것을 검토하며 질문을 구체화한다.
    3. AI에게 질문하여 답변을 얻고, 해당 질문과 답변을 노션에 기록한다.
    4. 추가 질문이 생긴다면 막힌 부분의 코드를 한 줄이라도 쓸 수 있는지 판단하고, 코드를 쓸 수 있으면 추가 질문을 기록만 하고 다시 미션을 진행한다.
    5. 코드를 작성할 수 없으면 AI에게 추가 질문을 한다.

### 3. 전략 평가
- 효과적이었던 것과 그 이유
    - 학습의 완료 조건을 막힌 부분의 코드를 한 줄이라도 쓸 수 있다로 설정하니, 학습 템포가 굉장히 빨라졌다. 이로 인해 미션 진행 시간이 많이 단축됐다.
- 비효과적이었던 것과 그 이유
    - 단순히 구현을 할 수만 있으면 더이상 학습하지 않고 미션을 진행하다 보니, 관련 지식에 대한 학습을 한다기보다는 AI가 알려주는 답을 코드로 옮기는 상황이 되어 학습을 했다는 느낌을 받지 못 했다.
      - 일례로 @Repository 어노테이션을 붙이지 않아 테스트가 실패했다. 그래서 AI에게 이유를 물어봤고, @Repository 어노테이션이 없기 때문이라는 답을 들었다.
      - 여기서 @Repository 어노테이션을 붙이고 테스트가 성공하는 것을 보고 학습 완료 조건이 충족하여 그대로 미션을 진행했다.
      - 그러나 실무에서 이렇게 한다면 회의에서 왜 @Repository를 붙였냐는 질문에 대답을 할 수 없을 것이라는 생각이 들었다.
    - 동시에 학습을 했다는 느낌을 받지 못 해 더 물어보려고 하면 그 시점에서부터 또 어디까지 물어보는 것이 좋을지 명확한 기준이 없었다.
- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?
    - 미션 수행에 있어서는 적절했지만, 학습에 있어서는 적절하지 않았다고 생각한다.
    - 3단계 미션을 하면서 크게 어렵거나 이해하지 못 한 개념들을 접하지 못 했는데, 그래서 더 깊게 파지 않고 딱 미션 수행에 필요한 부분만 학습해도 크게 어색하지 않았다.
    - 그러나 이 방식은 학습이라기 보다는 AI에게 정답만을 물어보는 느낌이 들어 개선이 필요하다고 생각한다.

### 단 하나의 개선점

> **완료 조건을 두 단계로 분리하세요. 미션 완료 조건과 학습 완료 조건을 따로 정합니다.**

구체적으로 이렇게 씁니다.

```
미션 완료 조건: 막힌 부분의 코드를 한 줄이라도 쓸 수 있다 (기존 유지)
학습 완료 조건: 이 코드가 왜 동작하는지 한 문장으로 말할 수 있다
```

@Repository 예시로 적용하면 이렇습니다.

```
미션 완료 조건 충족: @Repository를 붙였더니 테스트가 통과됐다
학습 완료 조건 확인: "@Repository는 스프링이 이 클래스를
  데이터 접근 객체로 인식하게 해서 빈으로 등록하기 때문이다"
  → 이걸 말할 수 있는가?
  → 말할 수 있으면 넘어간다
  → 말할 수 없으면 한 가지만 더 묻는다
```

### 왜 "한 문장"인가

더 깊이 물어보고 싶은데 어디까지 물어봐야 할지 모르겠다는 문제, 이것도 이 기준으로 해결됩니다. 한 문장으로 말할 수 있으면 멈춥니다. 말할 수 없으면 말할 수 있을 때까지만 묻습니다. 한 문장이 경계가 됩니다.

완벽한 이해가 아닙니다. 회의에서 "왜 @Repository를 붙였냐"는 질문에 한 문장으로 대답할 수 있는 수준입니다. 그게 지금 단계의 학습 완료입니다.
