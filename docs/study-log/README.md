# 미션 중 기록

해당 파일은 미션 중 기록을 다루고 있습니다.

### 구조

```shell
docs/
  study-log/
    README.md         ← 인덱스 + 학습법 v1 → v2 → v3 변천
    log-01.md         ← 각 로그는 개별 파일
    log-02.md
    log-03.md
```

## 학습법

### v1

```text
사실 : 레벨1에서 모르는 게 생기면 우선 책과 인공지능에게 어떻게 생각해야하는 지를 물어보고, 그것을 스스로 적용해보기 위한 시간을 많이 가졌다.

레벨 1에서도 "객체 지향을 마스터하겠다" 와 같은 추상적이고, 원대한 목표를 세웠습니다. 이러한 목표는 원대할 뿐만 아니라 완벽함을 동시에 추구하기 때문에 코드 완성도를 스스로 높이고자 하였고, 그 때문에 쉽게 지쳤다.
```
