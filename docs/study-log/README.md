## 🔄 학습법 변천사 (v1 → v2 → v3)

### v1 학습법 (초기: 지식 습득 중심)
- **도서 기반 학습:** 관련 도메인에서 유명한 도서를 읽는다.
- **AI 활용:** 읽으면서 생기는 궁금한 점을 AI에게 질문한다.
- **기록:** 다음에 또 필요할 것이라 판단되는 내용은 기록으로 남긴다.
- **검색 보완:** AI의 답변으로 부족할 경우 구글링을 통해 교차 검증한다.
- **크루 피드백:** 정답이 없어 보이는 주관적/설계적 문제에 대해서는 동료(크루)의 생각을 들어본다.

### v2 학습법 (발전: 목적 분리 및 예측 도입)
- **목적 가지치기:** 해결하거나 학습하고자 하는 목표를 AI의 도움을 받아 아주 작게 분리한다.
- **Predict (예측):** 분리된 각각의 목적에 대해, 정답을 찾기 전 내 생각으로 먼저 예측하고 가설을 세워본다.
- **Resourceful Input:** 공식 문서, AI, 책, 블로그 등 활용 가능한 모든 매체를 자유롭게 사용하여 인풋을 채운다.
- **Resourceful Output:** 글쓰기, 말하기, 모델링 등 다양한 방식을 활용하여 아웃풋을 도출한다.

### v3 학습법 (현재: 관심사 기반 딥다이브 및 백지 인출)
- **목적 가지치기 (학습 트리 만들기):** 학습 목표를 AI를 통해 작게 분리하되, **키워드 링크(관심사 기준)의 depth 3까지**를 바운더리로 설정하여 깊이와 범위를 통제한다.
- **Predict (예측):** 분리된 목적에 대해 내 생각으로 먼저 예측해본다.
- **Resourceful Input:** 공식 문서, AI, 책, 블로그 등을 자유롭게 활용하여 인풋한다.
- **Resourceful Output (강화):** 단순한 아웃풋이 아닌, **백지 상태에서** 글쓰기, 말하기, 모델링 등을 수행하여 진짜 내 지식이 되었는지 검증한다.
