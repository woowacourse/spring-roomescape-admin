### 2. 막힘 해결
1. 의존성 추가
  - 의존성 추가하는 방법을 확실하게 모름
    - AI에게 물어봄
    - `implementation`, `runtimeOnly` 차이가 궁금해짐
      - 크루가 알려줌. 구현체를 몰라도 되면 runtimeOnly로 사용하는게 좋음
    - 가이드 자료에는 `application.properties` 설정이 3개, AI는 6개 알려줌
    - 가이드 자료대로 해도 정상 동작 됨
2. 테이블 스키마 적용
  - `schema.sql` 파일을 만들고 나서 DB에 어떻게 적용해야하는지 알지 못함
  - 별도 초기화 클래스가 필요한지 고민해보다 AI에게 물어보기로 결정
  - 스프링부트가 스키마를 찾아서 자동으로 적용시켜준다는 것을 알았습니다.
3. 테스트의 어려움
  - `ReservationDao`를 테스트하려 했는데, 생성하기가 쉽지 않음
  - AI에게 물어보아 방법을 찾아봄
    - `@JdbcTest` 어노테이션: Spring Boot Test의 기능, 테스트용 DB를 자동으로 띄워주고 JdbcTemplate을 빈으로 등록해줌(`@Autowired`), JDBC 관련 설정만 로드해서 속도가 빠름, 새로운 테스트 도구에 해당하여 부적합
    - 순수 Java 방식으로 직접 객체 생성하기: 복잡하지만 이 방법으로 결정
```java
class ReservationDaoTest {  
  
    private ReservationDao dao;  
  
    @BeforeEach  
    void setup() {  
        DriverManagerDataSource dataSource = new DriverManagerDataSource();  
        dataSource.setDriverClassName("org.h2.Driver");  
        dataSource.setUrl("jdbc:h2:mem:database;DB_CLOSE_DELAY=-1");  
        dataSource.setUsername("sa");  
        dataSource.setPassword("");  
		
        JdbcTemplate jdbcTemplate = new JdbcTemplate(dataSource);  
		
        ResourceDatabasePopulator populator = new ResourceDatabasePopulator();  
        populator.addScript(new ClassPathResource("schema.sql"));  
        populator.execute(dataSource);  
		
        this.dao = new ReservationDao(jdbcTemplate);  
    }
}
```
4. 테스트 실패 문제
  - `MissionStepTest`와 `ReservationDaoTest`를 따로 실행시킬 때에는 문제가 없었는데, 동시에 실행시키니 문제가 생김
  - `dataSource.setUrl("jdbc:h2:mem:database;DB_CLOSE_DELAY=-1");`
    - 두 테스트 모두 같은 이름의 DB를 사용해서 문제가 발생하는 것을 AI를 통해 확인
    - `dataSource.setUrl("jdbc:h2:mem:reservation_dao_test;DB_CLOSE_DELAY=-1");` 로 코드 변경
5. 또 다시 테스트 실패 문제
  - 예약 추가 테스트 작성 완료 후 예약 삭제 테스트를 작성하였는데 둘이 동시에 실행시키니 또 에러가 남
  - `DB_CLOSE_DELAY=-1` 설정 때문에 첫 번째 테스트가 끝나도 `reservation` 테이블은 메모리에 그대로 살아있게 되고, 두 번째 테스트에서 테이블 생성 시 충돌 발생(AI를 통해 알아냄)
  - `schema.sql`파일을 수정하여 테이블 삭제 -> 생성하도록 권장
  - 테스트 때문에 스키마 파일을 변경하는 것은 좋지 않다고 생각하여 `JdbcTemplate`객체 생성 후 `jdbcTemplate.execute("DROP TABLE IF EXISTS reservation");` 실행하여 테이블 삭제
