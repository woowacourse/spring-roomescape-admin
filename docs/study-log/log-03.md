### 1. 막힌 것의 종류
이번에 막힌 것은 어떤 종류의 어려움이었는가? (해당하는 것에 체크)
- [ ] 개념 자체를 모르겠다 (예: "스프링 빈이 뭔지 모르겠다")

- [ ] 코드는 돌아가는데 이게 맞는 건지 모르겠다 (예: "계층 분리를 이렇게 해도 되나?")
- [x] 기타: 3단계를 진행하고 1,2단계의 테스트들을 3단계 형식에 맞춰서 수정할 때 어려움이 있었습니다.

### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
  - 2단계와 동일하게 문제 해결용 멘탈 모델 카드 5개를 AI의 도움을 받아 학습하는 전략이지만, 마지막에 퀴즈를 추가한 전략입니다.
  - 실행했습니다.
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
    ```
    이전 단계와 동일하게 문제해결용 멘탈 모델 카드 5개를 AI를 통해 학습을 하였고, 
    추가적으로 퀴즈를 통해 검증받는 방식으로 학습했습니다.
    
    퀴즈를 생성하는 템플릿은 아래와 같습니다.

    1. 총 5문제 이하로 만들어줘.
    2. 단순 암기 문제가 아니라, 실제 구현 상황에서 판단해야 하는 문제로 만들어줘.
    3. 문제 유형은 아래 비율로 구성해줘.

      - 개념 확인 1문제
      - 동작 흐름 1문제
      - 코드 적용 1문제
      - 실수/주의점 1문제
      - 실제 문제 상황 판단 1문제

    4. 정답은 바로 보여주지 말고, 내가 먼저 풀 수 있도록 문제만 먼저 보여줘.
    5. 내가 답을 제출하면, 그때 채점하고 틀린 이유와 다시 봐야 할 핵심만 설명해줘.
  
    퀴즈를 통해 학습했던 내용을 검사받는 과정에서 이해했다고 생각한 부분들이 
    생각보다 글로 잘 써지지 않는 것을 느꼈습니다. 퀴즈로 풀고 부족한 부분은 피드백을 받으면서
    이전에 퀴즈 없이 진행했던 방식보다 한층 더 깊이 이해가 된 것을 느꼈습니다.
    
    ```

### 3. 전략 평가
- 효과적이었던 것과 그 이유
  - 효과적이었던 것: 퀴즈를 통해 학습했던 내용을 검증받는 과정이 효과적이었습니다. 
  - 이유: 이해했다고 생각했던 개념들도 막상 퀴즈로 풀어보려고 하니 대답이 잘 나오지 않는 부분들이 많았습니다. 퀴즈를 통해 다시 한번 피드백을 받으면서 이해가 깊어지는 것을 느꼈습니다.
- 비효과적이었던 것과 그 이유
  - 딱히 없습니다.
- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?
  - 학습 테스트(RestAssured) 관련 학습은 진행하지 않아서 전략의 궁합을 측정하기에는 애매한 부분이 있습니다. 4단계를 다 마친 후 RestAssured에 학습전략을 적용해서 학습해 보겠습니다.
