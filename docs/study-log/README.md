# 학습 로그



### 나만의 학습법 (V2)
1. 먼저 블로그를 통해 가벼운 키워드를 뽑는다.
2. AI에게 내가 뽑은 키워드와 과제 사이의 연관 관계가 적절한지, 추가로 사용할 키워드가 있을지 평가받는다.
3. 뽑은 키워드를 기준으로 NotebookLM을 통해 공식문서에서 참고할 관련 페이지를 추천받는다.
4. 이때, 핵심 개념에서 벗어난 키워드 같은 경우 따로 적어둔다. (이후 또 등장하면 다시 공부)
5. AI와 대화를 통해 이해한 바가 맞는지 확인한다.
   (선택) 직관적으로 느낄 수 있게끔, 돌려볼 코드를 추천받는다.

### 최종 학습법 (V3)

1. 무엇인가, 왜 필요한가, 어떻게 구분/적용하는가 형태의 핵심 질문 3개를 먼저 만든다.(핵심 질문 3개와 필수 개념 1장 구조)
2. 1번 질문을 참고해서 ChatGpt 에이전트에게 정보 검색 수집을 요청하고, 나는 블로그 읽으며 키워드 추출한다.
3. 블로그에서 추린 키워드를 정리하고, AI로 핵심 주제에 맞는 키워드만 추린다.
4. 키워드와 ChatGpt 에이전트의 내용을 A4 1장으로 정리하고, 핵심 질문 3가지에 대한 답을 내 말로 정리한다.
5. ChatGpt와 추가적인 질문을 하며, A4 1장의 빈 부분이나 애매한 부분만 보완한다.
6. 이해한 내용을 3분 동안 말로 설명해본다.
7. ChatGpt에게 장애 상황이 포함된 실패 코드를 추천받는다.
8. 그 코드를 직접 트러블 슈팅하며 개념을 추가로 이해한다.
