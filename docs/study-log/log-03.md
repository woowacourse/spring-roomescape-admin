### 2. 이번 타임의 학습 전략

- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.

이번 학습은 복습하는 목적으로 주어졌기에 ai 사용을 최소화 했습니다.

주어진 키워드 [**`inner join`**, 객체 의존, 외래키]를 알고는 있지만 바로 사용할 수 있을 정도는 아니였기에 우선 키워드를 스스로 학습했습니다. 그 후 ai를 사용하지 않고 스스로 미션을 구현했습니다.

미션 요구사항 자체는 ai를 사용하지 않고 스스로의 힘으로 구현할 수 있었습니다. 하지만 요구사항 테스트 코드에 담겨진 문제 (시간 데이터를 먼저 넣어주지 않으면 테스트 실패 & 클래스 전체 테스트 실행 시 실행 순서에 따라 테스트 실패)는 스스로의 힘으로 해결하지 못했습니다. 해결할 방식을 생각하고 구현해보았지만 데이터 초기화가 안되는 문제가 계속 발생했고, 이때 ai의 도움을 받았습니다.

### 3. 전략 평가

- 효과적이었던 것과 그 이유
    - ai를 사용하지 않고 스스로 구현하기
        - ai의 도움을 받지 않고 스스로 구현하니 레벨 1,2 때 공부한 내용이 얼마나 나의 것이 되었고, 어떤 부분이 부족한 지 확인 할 수 있었습니다.
- 비효과적이었던 것과 그 이유
    - 구글링을 통해 공부를 하니 원하는 정보를 얻는데까지 오랜 시간이 걸린다는 점 빼고는 없는 것 같습니다.
    - (+ 앞 단계에서 ai를 적극적으로 활용하여 공부를 하다 ai를 사용하지 않으니 답답한 점이 있었습니다)
- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?
    - 키워드에 대해 스스로 공부하고 미션을 소단계 별로 구현하니, 마지막 소단계의 응용이 필요한 부분에서 스스로의 힘으로 구현할 수 있었습니다.
