# 방탈출 예약

## 1. Web Application 버전

- [x] `localhost:8080/admin` 요청 시 어드민 페이지가 응답한다.

### 1) 예약 관리 페이지

- [x] `localhost:8080/admin/reservation` 요청 시 예약 관리 페이지가 응답한다.
- [x] 현재 저장된 예약 목록을 조회할 수 있다.

#### 예약 추가/취소

- [x] 예약 추가 버튼을 누르면 예약이 추가된다.
- [x] 예약 취소 버튼을 누르면 예약이 취소된다.

### 2) 시간 관리 페이지

- [x] `localhost:8080/admin/time` 요청 시 시간 관리 페이지가 응답한다.
- [x] 현재 저장된 예약 시간 목록을 조회할 수 있다.

#### 예약 시간 추가/삭제

- [x] 예약 시간 추가 버튼을 누르면 예약 가능한 시간이 추가된다.
- [x] 예약 시간 삭제 버튼을 누르면 해당 시간이 삭제된다.

## 2. Console Application 버전

### 1) 사용 기능 선택

- [x] 사용할 기능 카테고리를 선택한다.
    - [x] `예약 시간 관리` 선택 시, 예약 시간 관련 기능 목록을 출력한다.
    - [x] `예약 관리` 선택 시, 예약 관련 기능 목록을 출력한다.

### 2) 예약 시간 관리

- [x] `예약 시간 추가`, `예약 시간 목록 조회`, `예약 시간 삭제` 중 하나를 선택한다.

#### 예약 시간 추가

- [x] 생성할 예약 시간을 `HH:mm` 형태로 입력받는다. (ex: 16:30)
- [x] 예약 시간이 정상적으로 생성되면 해당 예약 시간을 출력한다.

#### 예약 시간 목록 조회

- [x] 현재까지 저장된 예약 시간 목록을 출력한다.
    - 저장된 예약 시간 데이터의 아이디와 시간을 출력한다.

#### 예약 시간 삭제

- [x] 삭제하려는 예약 시간의 아이디를 입력 받는다. (ex: 1)
- [x] 예약 시간이 정상적으로 삭제되면 삭제 완료 문구를 출력한다.

### 3) 예약 관리

- [x] `예약 추가`, `예약 목록 조회`, `예약 삭제` 중 하나를 선택한다.

#### 예약 추가

- [x] 생성할 예약의 예약자 이름, 예약 날짜, 생성할 시간 아이디를 입력한다. (ex: 피글렛, 2025-04-24, 1)
- [x] 예약이 정상적으로 추가되면 해당 예약 정보를 출력한다.

#### 예약 목록 조회

- [x] 현재까지 저장된 예약 목록을 출력한다.
    - 저장된 예약 데이터의 아이디, 예약자명, 예약 날짜, 예약 시간을 출력한다.

#### 예약 삭제

- [x] 삭제하려는 예약 데이터의 아이디를 입력 받는다. (ex: 1)
- [x] 예약이 정상적으로 삭제되면 삭제 완료 문구를 출력한다.
