## 학습법 v1
일단 주어진 요구사항에 맞춰서 설계합니다. 설계하는 과정에서 불편함을 느끼거나 어려움을 느끼면 구글링과 AI를 사용해 해결합니다.

AI를 사용할 때는 시스템 프롬프트를 통해서 항상 내 의견에 대해서 비판적으로 생각하고 정답을 주지말고 역질문을 던지도록 설정해두었습니다. 

따라서 질답을 끊임없이 주고받으면서 납득할 때까지 논쟁하는 방식으로 공부합니다.

만약 그럼에도 불구하고 납득하지 못했거나 정답이 없는 설계의 고민이라면 크루, 리뷰어, 코치들과 토론하며 나만의 기준을 세우고 있습니다.

## 학습법 v2
구글링 + AI와의 토론, AI는 항상 내 의견에 대해서 비판적으로 생각하고 정답을 주지 않으며 역질문을 던지도록 설정해뒀습니다.

납득할 때까지 질답을 반복하며 논쟁하는 방식으로 공부합니다.

그럼에도 납득하지 못하거나 정답이 없는 설계의 고민은 크루, 리뷰어, 코치들과 토론합니다.

AI와 토론할 때 핵심적인 문제에 대해서는 질답의 depth를 5로 제한합니다.

추가적으로 필요한 선수 지식과 관련된 질답은 depth를 1로 제한합니다.

한 문제에 대한 질답은 20분을 넘지 않도록 합니다.

질답 이후에도 해결되지 않은 문제에 대해서는 기록하고 다시 돌아봅니다.
