## v3 — 단계별 심화 루틴

### 1. 시작 전: 왜 배우는가 한 줄 정의

학습을 시작하기 전, 목적을 한 줄로 적는다.

> 예: "JVM을 배우는 이유 → 자바 코드가 OS 상관없이 실행되는 원리를 이해하기 위해"

방향을 잃었을 때 돌아올 기준이 된다. 이 목적에서 벗어난 내용은 깊이 파지 않는다.

---

### 2. 선 이해

지금 당장 필요한 것만 학습한다. 한 번에 하나씩, 해소되면 더 이상 깊이 파지 않는다.

이 과정에서 AI, 강의, 유튜브, 블로그, 책 모든 것을 사용해도 된다.

---

### 3. AI에게 설명하고 피드백 받기

> log-02에서 수정. "소리내어 코딩" → "AI 설명 + 즉각 피드백"으로 변경

코딩하면서 막히는 순간, 또는 학습이 끝난 후 오늘 배운 개념 하나를 아무것도 보지 않고 AI에게 설명한다.

> 말로 설명하지 못하는 것은, 사실 이해하지 못한 것이다. 설명하다 막히는 순간이 바로 진짜 이해의 빈틈이다.

- 혼자 설명 → 막혀도 맞는지 틀린지 모름
- AI에게 설명 → 막히면 즉각 피드백, 틀린 부분 바로 잡힘

막히는 지점이 곧 4번 해소 기준 확인의 시작점이다.

---

### 4. 해소 기준 확인

> log-02에서 수정. 문장 혼자 채우기 → AI에게 설명하고 피드백 받는 방식으로 변경

오늘 배운 개념을 AI에게 설명한다.

- 설명이 맞으면 → 기록하고 넘어간다
- 막히거나 틀리면 → 즉각 피드백 받고 보완한다
- 보완 후에도 막히는 지점 → 다음 deep dive의 시작점이다

참고 형식:
> "___는 ___때문에 ___방식으로 동작한다. 그래서 ___상황에서 의미가 있다."
