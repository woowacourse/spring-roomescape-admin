### 4. AI 피드백

사용한 프롬프트

```text

1. 어떤 코드가 역직렬화를 시도했는지 찾는다.  
2. 어떤 클래스로 변환하려 했는지 확인한다.  
3. 해당 클래스에 Jackson이 사용할 수 있는 생성 방법이 있는지 본다.  
4. 기본 생성자 추가, @JsonCreator 사용, DTO 분리, JSON 직접 검증 중 하나를 선택한다.
```
