## 학습법 변천
### V1 (레벨 1)
1. 강의를 통해 정제된 지식을 전달받는 수동적 학습에 익숙해져 있었다.
2. 아무런 가이드 없이 스스로 시작점을 찾아야 하는 상황에서 무력감을 느꼈다.
3. 시간 압박 속에서 본질적인 이해 없이 구현에만 몰두했다.
4. AI에 피상적인 질문을 던지며 원론적인 답변에 그쳐 본질적인 갈증이 해소되지 않았다.
5. 해결되지 않은 궁금증이 기술 부채로 쌓이며 심리적 부담이 커졌다.
6. 부채를 빠르게 처내기 위해 다시 AI를 오남용하는 악순환에 빠졌다.
### V2 (스스로 생각한 문제점 해결 방법)
1. 목표와 난이도 명확하게 구축하기
2. 무작정 잘하려는 욕심보다는 현재 레벨에서 한 단계 업시키는걸 노리기
3. 배운걸 말한마디로 정리할 수 있게하고 크루에게 설명하기
4. 하루 한 번 배운것에 대한 기록 남기기
5. AI는 코드 작성자가 아닌 멘토로 활용한다 (중요지점은 AI가 판단)
6. 문제 내달라고 하기
### V3 (AI 피드백 반영)
```
막히는 순간, AI나 검색에 손대기 전에 종이에 10분간 손으로 적기.
코드를 짜다 손이 멈추는 순간, 다음을 실행.

종이(또는 메모 앱)를 펼치고 10분 타이머를 켠다.(시간은 유동적으로)
세 가지를 순서대로 적는다.
1. 내가 지금 만들려는 것은 무엇인가? (목표 한 문장)
2. 내가 모르는 것은 정확히 무엇인가? (가능한 한 좁혀서)
3. 내가 추측하는 답은 무엇인가? (틀려도 좋으니 가설)

10분이 지난 후에야 AI·구글·동료에게 질문한다.

핵심 원칙

완벽하게 지키려 하지 않는다. 첫 주는 절반만 지켜도 성공.
기존 6개 원칙을 의식하지 않는다. 이 한 가지가 자동화되면 나머지(목표 명확화, 한 마디 정리, AI 멘토화, 기록)는 자연스럽게 따라온다.
점검은 미션 단위로 한 번씩. "이 규칙을 몇 번 적용했고 그때 무슨 일이 있었는가"만 회고에 남긴다.
```
