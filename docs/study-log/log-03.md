### 2. 이번 타임의 학습 전략

- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
    - '돌아가게 만든 뒤 리팩터링하는 전략'을 사용했다.
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.

복습 위주의 단계라서 학습을 미리 하지 않고 코드를 작성하였다.
돌아가게 만든 후에 추가 요구사항인 ReservationTime 클래스를 작성하였다.
요청 형식이 바뀌었기 때문에 요청 형식에 알맞은 ReservationRequest 클래스를 작성하였다.
리팩토링을 위해 Reservation의 timeId를 ReservationTime으로 수정하며 요구사항에 맞게 코드를 수정하였다.
리팩토링을 하며 요청/응답의 형식에 맞추는 부분을 학습하였다.

### 4. AI 피드백

- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고,
  유용했던 제안 1가지 이상 기록

유창성의 함정(Fluency Illusion) 주의:
"복습이라 학습하지 않고 시작했다"는 부분에서 주의할 점이 있습니다.
우리 뇌는 익숙한 코드를 보면 '알고 있다'고 착각하기 쉽습니다.

제안: 코드를 치기 전, '백지 복기' 전략을 짧게 사용해 보세요.
"지난번에 학습한 예약 로직의 흐름을 1분 안에 그려보기" 같은 활동을 거친 뒤 코딩을 시작하면, 뇌가 훨씬 더 능동적으로 정보를 인출하게 됩니다.
