### 2. 이번 타임의 학습 전략

- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
  ```text
    depth의 기준: 직접적 증거인가? (Distance: 1) / 원리를 설명하기 위한 부차적 정보인가? (Distance: 2) / 그 원리의 내부 구현인가? (Distance: 3+) -> 나중에 알아볼 목록에 적어두기
    ```
    위의 기준으로 depth를 판단해보는 전략을 시도해보았다.

- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.

  이전에 했던 것 처럼 처음에 따로 노션에 목표를 작성해두고, LLM에게 질문을 던져가며 진행했다. 이번 목표는 '@Valid 동작 원리를 내가 설명할 수 있을 만큼 알아보자'였다.
  AI와 대화를 하면서 새롭게 만든 기준을 근거로 depth를 계산하며 질문했다.
  중간에 `HandlerMethodArgumentResolver`,`RequestResponseBodyMethodProcessor` 등 리졸버와 `@RequestBody`를 처리하는 구현체에 대해서 알아보게 될 뻔 했으나, 이전의 기준을 통해 기술부채에 넣어두고 이전 질문으로 돌아가 진행해보았다.
  그 결과 Valid의 동작 시점(컨트롤러 메서드 실행 전, ArgumentResolver 사용 중)과 BindingResult로 어떤 식으로 유효 값을 관리할지 생각할 수 있었다.
