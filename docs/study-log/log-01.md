### 1. 막힌 것의 종류

이번에 막힌 것은 어떤 종류의 어려움이었는가? (해당하는 것에 체크)

- [ ] 개념 자체를 모르겠다 (예: "스프링 빈이 뭔지 모르겠다")
- [ ] 개념은 알겠는데 코드로 어떻게 쓰는지 모르겠다 (예: "JdbcTemplate 문법을 모르겠다")
- [X] 코드는 돌아가는데 이게 맞는 건지 모르겠다 (예: "계층 분리를 이렇게 해도 되나?")
- [ ] 기타: ___

### 2. 이번 타임의 학습 전략

제공된 학습 테스트를 기반으로 학습하고 직접 공식문서를 기반으로 AI 없이 학습해보기

### 3. 전략 평가

- 학습 테스트가 잘 제공되어있어, 테스트에서 힌트를 얻을 수 있었다.
- AI를 사용하지 않고 작성하다보니, 헷갈리는 지점에 대해서 빠르게 얻을 수 없었다.
- 코드가 돌아가는데 이게 맞는 지를 따로 검토하기는 어려웠다. 왜냐하면 스프링을 많이 사용해보지 않은 터라 돌아가기는 했지만, 다양한 영역에서 이게 맞는 코드일까? 이렇게 해도 되는걸까? 하는 궁금증이 계속해서
  남았다고 생각한다.

### 4. AI 피드백

#### AI를 판단 기준을 세워주는 리뷰어로 사용하자.

멘탈 모델로 보면, 새로운 기술 학습에는 세 층이 있습니다.

- 문법 모델: 어떻게 쓰는가
- 동작 모델: 내부에서 어떻게 흘러가는가
- 판단 모델: 언제 어떤 선택을 하는가

이번 전략은 1, 2번에는 강하지만 3번이 비어 있습니다.

- AI를 구현 도우미가 아니라 구현 후 판단 기준을 만들어주는 리뷰어로만 쓰세요.

#### 판단 기준을 기록해놓고 AI에게 물어보자.

### 5. 다음 타임에 바꿀 것

- 제공된 학습 테스트를 그대로 이어가되, AI를 판단의 기준을 평가받는 리뷰어로 사용한다.
