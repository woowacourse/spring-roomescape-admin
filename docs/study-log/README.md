## 학습법
### v1
```
1. 전체 틀 잡기
    - 책이나 개인 프로젝트로부터 여러 키워드를 뽑아낸다.
    - 책과 AI를 통해 키워드를 한 두문장으로 정리한다.
2. 내 것으로 만들기
    - 개인 공부를 하거나 토론 시간에 설명 못하는 게 있다면 기록해둔다.
    - 개인 시간에 AI와 책을 활용해 그 키워드를 학습한다.
    - 옵시디언 excalidraw 플러그인을 활용해 마인드맵을 그리면서 "질문-대답-질문-대답"을 반복한다.
```

### v2
```
1. 전체 틀 잡기
    - 책이나 개인 프로젝트로부터 여러 키워드를 뽑아낸다.
    - 책과 AI를 통해 키워드를 한 두문장으로 정리한다.
2. 내 것으로 만들기
    - 개인 공부를 하거나 트론 시간에 설명 못하는 게 있다면 키워드만 기록한다.
    - 개인 시간에 AI와 책을 활용해 키워드를 학습한다.
        - AI 사용 시 PiFSR 방식을 루트 프로젝트 프롬프트로 설정한다.
    - 옵시디언 excalidraw 플러그인을 활용해 "질문-대답-질문-대답" 반복하는 마인드맵을 그린다.
```

### v3
```
핵심 철학: "입력은 짧게, 출력은 자주, 검증은 코드로"
1. 전체 틀 잡기
    - 책이나 프로젝트에서 키워드 추출
    - 책/AI를 활용해 키워드를 한두 문장으로 정리
    - 이 단계는 "주제 선정"용으로만 활용. 깊이 들어가지 않음
2. 내 것으로 만들기
    1. AI를 켜기 전에 본인이 아는 만큼 또는 몰라도 내 생각대로 글로 풀어본다
        - 종이에 손으로 쓰기(절대 5분 넘기지 않기)
    2. 타겟 질문하기: 막힌 지점만 AI에게 질문한다
    3. 코드로 검증하기: IDLE을 무조건 켠다. 안 되는 주제면 패스한다.
    4. 마인드 맵을 그리면서 개념을 이어나간다.
    5. 마지막 한 줄 요약한다.
```
