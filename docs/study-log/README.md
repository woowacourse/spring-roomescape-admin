🏁 학습법 v1


레벨 1 초반에는 모르는 부분이 나오면 AI를 활용해 개념과 기초를 빠르게 훑고, 전체 흐름을 파악한 뒤 바로 코드로 옮겨보는 방식으로 학습했다. 
낯선 용어가 많아 흐름이 자주 끊기기도 했지만, 키워드를 빠르게 정리하면서 학습 속도를 끌어올릴 수 있었다. 
더 깊이 이해가 필요한 부분은 책을 참고하거나 스터디를 통해 크루들과 의견을 나누며 보완했다.

🚀 학습법 v2

AI에게 답을 받기 전에, 먼저 스스로 5분이라도 고민하는 시간을 갖는다. 
받은 뒤에는 왜 이렇게 동작하는가를 한 문장으로 내 말로 설명할 수 있을 때까지 자료를 찾아본다.

🔥 학습법 v3 

막히는 순간, AI에게 답 대신 힌트를 요청한다. 
힌트를 받으면 내 언어로 한 문장 답을 써본 뒤 다음 힌트로 넘어간다. 
최종적으로 전체 흐름을 내 말로 설명할 수 있을 때 이해한 것으로 간주한다.
