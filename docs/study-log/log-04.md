### 1. 막힌 것의 종류
이번에 막힌 것은 어떤 종류의 어려움이었는가? (해당하는 것에 체크)
- [ ] 개념 자체를 모르겠다 (예: "스프링 빈이 뭔지 모르겠다")

- [ ] 코드는 돌아가는데 이게 맞는 건지 모르겠다 (예: "계층 분리를 이렇게 해도 되나?")
- [x] 기타: 관련 지식들은 배웠는데, 어떤 개념이었는지 바로 떠오르지 않는 것들이 있었다.

### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략
    - 검색 엔진을 사용하지 않고, AI만을 활용해서 개념 학습을 진행한다.
    - 학습을 시작하기 전에 "이 학습이 끝났다고 판단할 기준"을 먼저 정한다.
    - 학습 시작 전, 미션 완료 조건과 학습 완료 조건을 나눠서 먼저 생각해라.
      - 미션 완료 조건 : 막힌 부분의 코드를 한 줄이라도 쓸 수 있다.
      - 학습 완료 조건 : 특정 해결 방법을 사용한 근거를 설명할 수 있다.
    - AI에게 묻기 전, 내가 이미 아는 것과 모르는 것의 경계를 검토한다.
    - 꼬리 질문이 생겼을 때 이렇게 자문한다. "이걸 몰라도 지금 당장 코드를 한 줄이라도 쓸 수 있고, 그 코드에 대한 근거를 설명할 수 있는가?" 설명할 수 있으면 꼬리 질문을 메모만 하고 멈춘다. 쓸 수 없으면 그것이 다음 질문이 된다.
    - 개념을 먼저 배우고 코드를 짜는 것이 아니라, 코드를 먼저 짜다가 막히는 지점에서만 AI에게 묻는다.
- 실제 학습 과정
    1. 우선 미션 진행이 가능한 부분에 대해서는 진행을 한다.
    2. 미션을 진행하다가 헷갈리거나 궁금해서 막히는 부분이 생기면 노션에 질문을 작성한 다음, 아는 것과 모르는 것을 검토하며 질문을 구체화한다.
    3. AI에게 질문하여 답변을 얻고, 해당 질문과 답변을 노션에 기록한다.
    4. 추가 질문이 생긴다면 막힌 부분의 코드를 한 줄이라도 쓸 수 있는지, 그 코드에 대해 근거를 설명할 수 있는지 판단하고, 설명할 수 있으면 추가 질문을 기록만 하고 다시 미션을 진행한다.
    5. 코드를 작성할 수 없으면 AI에게 추가 질문을 한다.

## 단 하나의 개선점

> **다음 단계에서는 전략을 추가하는 대신, 지금 전략이 더 어려운 미션에서도 작동하는지 검증하는 것을 목표로 삼으세요.**

지금 전략은 충분히 좋습니다. 지금 필요한 것은 새로운 전략이 아니라 검증입니다.
