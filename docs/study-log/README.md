## 학습법 v1 → v2 → v3 변천

## 학습법 v1
1. 검색을 통해 문서를 먼저 찾아보았다. 
2. 도저히 감이 안 잡힐 때, 시간이 많이 소요 됐을 때 AI에게 물어보았다. 
3. 하나의 글을 읽고 애매하다면 다른 글도 참고했다. 
4. 방대한 개념을 잡기 위해 도서 읽기도 시도했다. 
5. 물리적인 시간의 부족함에 막혔다. AI를 통해 빠르게 학습했다. 

## 학습법 v2
1. AI 검색을 통해 공식 문서 자료, 추천 도서의 관련 목차를 찾고 학습한다.
2. 내용이 이해가 되지 않는다면 크루를 찾아간다.
3. 이해한 내용을 기반으로 AI에게 검증 받는다.
4. 노션, 옵시디언 등 큰 개념 타이틀만 적은 후 해당 내용을 서술해본다.
5. 막힌다면, 내용의 정리가 부족하다고 판단하여 AI와 다시 정리를 진행해본다.
6. 크루에게 해당 내용을 말로 설명해본다.
7. 말로 설명이 잘 안된다면(나만의 언어로 표현하지 못한다면) 4번부터 다시 시도한다.

## 학습법 v3
1. 학습할 핵심 개념 A를 하나만 정한다
2. AI 검색을 통해 공식 문서 자료, 추천 도서의 관련 목차를 찾는다
3. 학습 중 새로 나온 개념은 ‘보류 목록’에 적는다
4. 공식 문서나 책 내용을 읽고 큰 개념 타이틀만 적는다
5. 각 타이틀 아래에 ‘내 언어로’ 서술한다
6. 막히면 AI에게 ‘A 범위 내에서만’ 질문한다
7. 이해한 내용을 AI에게 검증받는다
8. 크루에게 말로 설명한다
9. 설명이 안 된 부분만 다시 4번으로 돌아간다
10. 보류 목록에서 다음 개념 하나를 선택한다
