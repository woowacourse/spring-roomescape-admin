## 주말에 시도할 것

주말에 시도할 것: Flowmodoro

적용 시나리오:

1. 리뷰와 코드 수정 시 집중력이 떨어질 때까지 작업을 수행한다.
2. 집중이 떨어진 경우 (타이핑 혹은 필기를 3분 이상 하고 있지 않은 경우) 휴식을 취한다. 휴식은 집중 시간의 1/5만큼을 쉰다.
3. 집중하며 적용한 내용 설명(버벅거리는 것 무관)이 어려운 경우가 3회 발생하면 전략 변경을 고려한다.
