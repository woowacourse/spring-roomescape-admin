### 학습법 v1
1. 모르는 개념은 강의나 책을 통해 학습한다.

### 학습법 v2
1. 모르는 개념을 먼저 검색하여 간략하게 지식을 습득한다.
2. 마인드맵으로 나만의 언어로 정리해본다. 간략한 코드도 함께 작성한다.
3. 관련 개념 중 모르는 부분을 마인드맵을 통해 파악한다.
4. 해당 개념을 정리하여 AI에게 퀴즈를 내달라고 한다.

### 학습법 v3
1. 모르는 개념을 먼저 검색하여 간략하게 지식을 습득한다. (언제, 왜 쓰는가 위주로)
2. 마인드맵으로 나만의 언어로 정리해본다. 간략한 코드도 함께 작성한다.
3. 관련 개념 중 모르는 부분을 마인드맵을 통해 파악한다.
4. 단, 2~3번 진행 시 유사 개념을 의도적으로 함께 배치하여 비교한다. (인터리빙)
5. 다음날 AI 면접 형식으로 검증한다.

### 개인 정리
주말에 시도할 것: "문제를 쪼개고, 딱 한 단계 어려운 것만 도전하라." (i+1 원칙 강화)

적용 시나리오:
1. 토요일 오전 Gradle 학습 시, 사용 이유에 대해서만 먼저 공부한다.
2. 오후에 build.gradle 추가로 공부한다. 
3. 한 번에 너무 많은 개념 공부를 하고 싶은 충동이 들면 멈춘다
