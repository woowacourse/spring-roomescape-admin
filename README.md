## 요구사항 정리

방탈출 카페 관리자가 전화·현장 예약을 직접 등록·관리하는 상황에 필요한 예약 관리 API를 만든다.

- [ ] 새로운 예약을 추가하는 API를 만든다.
    - [ ] 예약자 명이 빈칸이면 예외를 던진다.
    - [ ] 예약자 명이 null이면 예외를 던진다.
    - [ ] 예약 날짜가 null이면 예외를 던진다.
    - [ ] 예약 날짜 형식이 올바르지 않으면 예외를 던진다.
    - [ ] 예약 시간이 null이면 예외를 던진다.
    - [ ] 예약 시간 형식이 올바르지 않으면 예외를 던진다.
- [ ] 예약을 삭제하는 API를 만든다.
    - [ ] 존재하지 않는 예약을 삭제하면 예외를 던진다.
- [ ] 예약을 조회하는 API를 만든다.

<br>

## API 명세

---

### 1. 예약 추가 API

**설명:** 새로운 예약을 생성한다.

**메서드/URL**: `POST /reservations`

**요청 본문**

| 필드명      | 타입     | 설명    | 비고         |
|:---------|:-------|:------|:-----------|
| **name** | String | 이름    |            |
| **date** | String | 예약 날짜 | YYYY-MM-DD |
| **time** | String | 예약 시간 | HH:mm      |

```json
{
  "name": "브라운",
  "date": "2023-08-05",
  "time": "15:40"
}
```

**응답**

| 필드명      | 타입     | 설명                 |
|:---------|:-------|:-------------------|
| **id**   | Long   | 예약 고유 번호           |
| **name** | String | 이름                 |
| **date** | String | 예약 날짜 (YYYY-MM-DD) |
| **time** | String | 예약 시간 (HH:mm)      |

* **Status**: `200 OK`
    ```json
    {
      "id": 1,
      "name": "브라운",
      "date": "2023-08-05",
      "time": "15:40"
    }
    ```

---

### 2. 예약 삭제 API

**설명:** 특정 예약을 삭제한다.

**메서드/URL**: `DELETE /reservations/{id}`

**경로 변수**

| 변수     | 타입   | 설명            |
|:-------|:-----|:--------------|
| **id** | Long | 삭제할 예약의 고유 번호 |

**응답**

* **Status**: `200 OK`
    ```text
    -
    ```

---

### 3. 예약 조회 API

**설명:** 예약된 모든 내역을 조회한다.

**메서드/URL**: `GET /reservations`

**요청 본문**: `-`

**응답**

| 필드명      | 타입     | 설명                 |
      |:---------|:-------|:-------------------|
| **id**   | Long   | 예약 고유 번호           |
| **name** | String | 이름                 |
| **date** | String | 예약 날짜 (YYYY-MM-DD) |
| **time** | String | 예약 시간 (HH:mm)      |

* **Status**: `200 OK`
    ```json
    [
            {
                "id": 1,
                "name": "브라운",
                "date": "2023-08-05",
                "time": "15:40"
            },
            {
                "id": 2,
                "name": "네오",
                "date": "2026-04-28",
                "time": "16:40"
            }
        ]
    ```

---

### 4. 시간 추가 API

**설명:** 새로운 시간대를 생성한다.

**메서드/URL**: `POST /times`

**요청 본문**

| 필드명         | 타입     | 설명 | 비고               |
|:------------|:-------|:---|:-----------------|
| **startAt** | String | 시간 | YYYY-MM-DD HH:mm |

```json
{
  "startAt": "19:00"
}
```

**응답**

| 필드명         | 타입     | 설명        |
|:------------|:-------|:----------|
| **id**      | Long   | 시간대 고유 번호 |
| **startAt** | String | 시간        |

* **Status**: `200 OK`
    ```json
    {
      "id": 1,
      "startAt": "19:00"
    }
    ```

---

### 5. 시간대 삭제 API

**경로 변수**

| 변수     | 타입   | 설명             |
|:-------|:-----|:---------------|
| **id** | Long | 삭제할 시간대의 고유 번호 |

**응답**

* **Status**: `200 OK`
    ```text
    -
    ```

---

### 6. 시간대 조회 API

**설명:** 모든 시간대 내역을 조회한다.

**메서드/URL**: `GET /times`

**요청 본문**: `-`

**응답**

| 필드명         | 타입     | 설명       |
|:------------|:-------|:---------|
| **id**      | Long   | 예약 고유 번호 |
