# 기능 구현 목록

## 1. 예약 추가 (POST)
- [ ] `POST /reservations` 요청을 처리하는 엔드포인트를 구현한다.
- [ ] 요청 Body로 `name`, `date`, `time`을 JSON 형태로 전달받는다.
- [ ] 예약을 메모리에 저장하고, 새롭게 발급된 `id`를 포함한 예약 정보 전체를 JSON으로 반환한다.
- [ ] 정상적으로 생성 시 `200 OK` 상태 코드를 반환한다.

## 2. 전체 예약 조회 (GET)
- [ ] `GET /reservations` 요청을 처리하는 엔드포인트를 구현한다.
- [ ] 저장된 전체 예약 목록(id, 이름, 날짜, 시간)을 JSON 배열 형태로 반환한다.
- [ ] 정상적으로 조회 시 `200 OK` 상태 코드를 반환한다.

## 3. 예약 삭제 (DELETE)
- [ ] `DELETE /reservations/{id}` 요청을 처리하는 엔드포인트를 구현한다.
- [ ] URL 경로 변수(Path Variable)로 전달받은 `id`에 해당하는 예약을 찾아 삭제한다.
- [ ] 삭제 성공 시 응답 본문 없이 `200 OK` 상태 코드를 반환한다.
- [ ] 전달받은 `id`에 해당하는 예약이 없을 경우 `404 Not Found` 상태 코드를 반환하도록 예외 처리를 구현한다.
