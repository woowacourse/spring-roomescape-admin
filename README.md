# 방탈출 예약

## 홈화면
- [x] `localhost:8080/admin` 요청 시 어드민 페이지가 응답한다.

## 예약 관리

### 예약 조회
- [x] `/admin/reservation` 요청 시 예약 관리 페이지가 응답한다.

### 예약 추가
- [x] 예약 추가 버튼을 누르면 예약이 추가된다.
- [x] 예약 시 예약자 이름, 예약일자, 예약시간을 반드시 입력해야 한다.
- [x] 예약 시 예약시간을 지정된 값에서 선택할 수 있어야 한다.
- [ ] 동일한 예약자는 한 타임에 중복된 예약을 추가할 수 없다. 

### 예약 취소
- [x] 예약 취소 버튼을 누르면 예약이 취소된다. 

## 시간 관리

### 시간 조회
- [x] `/admin/time` 요청 시 시간 관리 페이지가 응답한다.

### 시간 추가
- [x] 예약 추가 버튼을 누르면 시간이 추가된다.
- [ ] 이미 존재하는 예약 시간을 중복하여 추가할 수 없다.

### 시간 삭제
- [x] 삭제 버튼을 누르면 시간이 삭제된다.
