### 2. 이번 타임의 학습 전략

### 3. 전략 평가
- 효과적이었던 것과 그 이유
  - ai에게 질문을 통해 처음 접하는 키워드들을 학습할 경우 빠른 이해가 가능했다. 당장 심오하게 파고들지 않고 미션 수행에 지장이 없을 정도로 학습하기에는 안성맞춤이었다고 생각한다.
- 비효과적이었던 것과 그 이유
  - 아무래도 미션 진행에 급급하다보니 수박 겉핥기 식으로 학습하는 느낌은 지울 수가 없었다. 스스로 완벽히 이해했냐는 물음과 나중에 응용할 수 있냐는 질문에 답할 수 없었다.
- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?
  - 50%정도라고 생각한다. 당장 미션 진행에는 효과적이지만 장기적으로 봤을 경우 효과가 있을지는 확신할 수 없다고 생각한다.

### 4. AI 피드백
- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고,
  유용했던 제안 1가지 이상 기록
  - 한 줄 책임 요약 연습: 단기 기억 한계를 극복하기 위해, 코드 한 줄마다 '책임'을 부여하는 연습입니다. 
    - 실행 방법: 미션을 마친 후, 내가 작성한 주요 클래스나 메서드 옆에 주석으로 '딱 한 문장의 책임'을 적으세요. 예를 들어 ResponseEntity 옆에 "HTTP 응답 상태 코드와 데이터를 캡슐화하여 클라이언트에게 명확한 결과를 전달하는 역할"이라고 적는 식입니다.
  - 자기 피드백 제약 연습: 미션이 돌아가는 것에 만족하지 말고, 일부러 제약을 걸어 다시 시도하며 뇌를 자극하세요.
    - 실행 방법: AI의 도움으로 미션을 해결했다면, 전체 코드를 지우고(혹은 새 브랜치에서) 15분 동안 AI 없이 핵심 로직만 다시 작성해 보세요. 이때 막히는 부분이 있다면 그곳이 바로 당신의 '진짜 학습 포인트'입니다.
