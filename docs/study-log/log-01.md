### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?  

원래는 토론을 통해 나온 v3 학습법으로 하려고 했는데, v3 학습법이 하나의 개념을 깊게 파고드는 공부법이라 마감 기한이 촉박한 미션에서 적용하기는 어려웠습니다.
어떤 개념을 공부해야하는지 조차 모르는 상태라서, 해당 학습법으로 진행할 수 없다는 판단이 들어 학습 방법을 새로 찾았습니다.
그러다보니 1 단계에서 굉장히 시간이 많이 걸리고 많이 헤맸습니다.

```text
[시도해본 학습법]
학습의 진입점을 찾기 위해 아래의 방법들을 사용해보았습니다.

1)블로그 기반 공부 -> 사람마다 설명이 달라서 더 헷갈리고, 과제 관련 개념인지 파악하기 어려웠다.
2)AI 기반 공부  -> Ai가 제안해준 정보에만 파고드는 경향이 있어서, 시야가 좁아지는 것 같다. 거짓 정보인지 파악하기가 어렵다.
3)학습 테스트 기반 공부 -> 기능 구현에 필요한 코드가 바로 나와있어서, 왜 이렇게 구현하는 건지에 대해 스스로 생각해보는 것이 어려웠다. (이미 구현이 되어있어서)

```

- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.

[학습법 - "나에게 집중해서 학습하기"]
1. 집중할 하나의 필수개념을 정의하고, 내가 아는 것을 작성하며 내 상황을 체크한다.
2. 기능을 구현하기 위한 과정에 궁금한 질문 1개씩 내고, 해당 질문에 대한 답할 정도로의 범위만을 공식문서 기준으로 공부한다.
3. 이해하기 어려운 문장은 GPT에게 설명을 요구하고, 내용을 정리한다.
- 만약 중간에 학습 방향을 모르겠다는 느낌이 들면, 현재까지 정리한 내용을 모두 AI에 넣어 다음 스탭을 추천받는다.
4. 한 단계가 끝났으면 정리한 모든 내용을 ChatGPT에게 넣어서 맞는지 확인한다.   
이때, AI는 바로 정답을 설명해주는 것이 아닌 스스로 생각할 수 있게 질문을 해주도록 프롬프팅한다.
```text
[프롬프트]
{정리한 내용}
내가 이번 학습하면서 배운 내용이야 틀린 부분이 있는지 봐줘. 
그리고 학습자이니까, 정답보다는 질문을 통해 스스로 생각해보고 싶어
정답은 그냥 넘어가고, 틀린 개념은 질문을 통해 다시 물어봐줘
```
5. ChatGPT 답변으로 기존에 정리했던 질문들에 연관지어서 내용을 정리한다.


### 3. 전략 평가
- **효과적이었던 것과 그 이유**   
질문을 통해 개념을 학습하는 것과 공식문서를 기반으로 학습하는 것이 효과적이었다.
공식 문서가 이 기능을 만든 사람의 의도가 담겨있다보니 개념을 더 잘 이해할 수 있었고, 
질문을 바탕으로 학습하니 기억에도 잘 남고 공부 범위를 좁히고 핵심에 집중할 수 있었다


- **비효과적이었던 것과 그 이유**   
블로그를 보는 것이 비효과적이었던 것 같다.     
과제와 관련이 없는 정보들도 많고, 사람들의 주관이 섞이 설명이 있으니 더 헷갈렸다.
블로그는 초기에 백지 상태보다는 조금 더 개념이 확립된 후에 보는 것이 좋을 것 같다.


- **막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?**    
코드 구현하는데 있어서는 공식 문서보다 학습 테스트가 더 많이 도움이 되었다.
대신 공식문서를 읽음으로써, 학습 테스트 코드에 대해 "아 그렇구나"하고 넘어가지 않고, 왜 이렇게 구현했을까를 스스로 질문할 수 있어서,
개념 이해 측면에서는 굉장히 도움이 많이 되었다.

### 4. AI 피드백
- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고, 유용했던 제안 1가지 이상 기록    
토론 활동 때 나온 5인의 전문가에게 물어보았을 때, 공통적으로 "AI 검증 전에 먼저 스스로 회상/설명하기"를 제안해주었다.

### 5. 다음 타임에 바꿀 것
- 유지할 것과 그 이유    
하나의 질문을 정하고, 그 질문을 답할 정도의 범위로 공부 범위를 제한한다.
질문에 답한 후, AI에게 피드백을 받아서 정리한다. 

질문을 먼저 하니까, 이 내용이 질문에 답과 무관해보이면 과감하게 skip할 수 있었다. 
이것이 공부 범위를 핵심 개념에 집중하게 해주는 것 같아서 유지하려고 한다.


- 바꿀 것과 그 이유    
백지 상태에서 지금 당장 떠오르는 질문을 꼬리에 꼬리를 물어서 답했는데, 다음 단계에서는 AI에게 먼저 과제를 보여주고 관련 개념을 설명 받으려고 한다.
왜냐하면, 개념을 모르는 상태로 질문을 하려고 하니 너무 많은 시간이 걸리고, 학습 방향을 잡기 막막했다.
과제와 연관이 있는 개념인지 파악하기가 어려워서 많이 헤맸기 때문에, 다음 단계에서는 AI에게 먼저 과제를 보여주는 방식을 시도해보겠다.
