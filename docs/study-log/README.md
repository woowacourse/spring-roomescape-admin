# 학습법 v1

```
1. 모르는 문제나 개념을 만난다.
2. 알고 있는 지식을 바탕으로 유추해 본다.
3. 유추한 내용을 바탕으로 어떻게 구현할지 고민한다.
4. 고민한 내용을 일단 동작하는 코드로 작성한다.
5. 코드 작성 이후 AI에게 해당 개념에 대해 질문한다.
6. 직접 구현하며 겪은 경험과 AI의 답변을 연결해 개념을 이해한다.
7. 남은 의문점에 대해 AI에게 추가 질문한다.
```

# 학습법 v2

```
1. 모르는 문제나 개념을 만난다.
2. +) 학습 목표를 먼저 명확히 정한다.
3. 알고 있는 지식을 바탕으로 해당 개념을 유추해 본다.
4. 유추한 내용을 바탕으로 어떻게 구현할지 고민한다.
5. 고민한 내용을 일단 동작하는 코드로 작성한다.
6. 코드 작성 이후 AI에게 해당 개념에 대해 질문하며 검증한다.
7. AI의 답변을 바탕으로 코드나 이해한 내용을 개선한다.
8. 남은 의문점이 있다면 AI에게 추가 질문한다.
9. +) 처음 정한 학습 목표가 달성되면 학습을 일단 종료한다.
```

# 학습법 v3

```
1. 모르는 문제나 개념을 만난다.
2. 학습 목표를 “이해하기”가 아니라 “할 수 있는 행동”으로 정의한다.
3. 목표를 달성할 수 있는 가장 작은 실행 단위로 쪼갠다.
4. 알고 있는 지식으로 결과를 예상한다.
5. 직접 수행한다.
6. 예상과 실제 결과의 오차를 확인한다.
7. 오차 원인을 이해하고 수정한다.
8. 목표한 행동을 할 수 있게 되면 학습을 일단 종료한다.
9. 학습 중 생긴 꼬리 질문은 즉시 파고들지 않고 따로 메모하여 추후에 학습한다
```
