## 학습법 변천
### 학습법 v1
- 처음에는 검색을 통해 문서, 블로그 글 등으로 학습해보려 했지만 시간 대비 효율이 떨어진다고 판단하여 이후부터는 AI에 전용 프롬프트를 입력하여 페르소나를 만들고 대화를 진행하며 학습하였다.
### 학습법 v2
- 모르는 개념들이 나왔을 때, 너무 깊은 내용까지 공부하려 하지 말고 딱 필요한 부분만 공부한다.
    - 그 후 하나씩 추가해나간다.
- ai로 학습 후 자신만의 언어로 다시 정리해보는 백지 복습 해보기(아날로그 or 타이핑)
### 학습법 v3
- 트러블 슈팅 연습
    - 완성된 시스템의 특정 부품을 의도적으로 고장낸 뒤 이를 복구하는 과정을 학습 루틴에 넣는다.
    - 코드가 정상 작동하면, 스스로 “DB 연결이 갑자기 끊긴다면?”, “잘못된 형식의 JSON이 들어온다면?”과 같은 과제를 던지고 시스템이 어떻게 반응하는지 관찰한 뒤 예외처리를 구현한다.
- 비유를 통한 시스템 매핑
    - 추상적인 백엔드 개념을 전혀 다른 분야의 익숙한 개념과 1:1로 매핑하여 설명하는 연습을 한다.
    - 비유를 통해 이미 알고 있는 맥락을 제공하면 뇌는 이를 중요한 정보로 인식하고 더 오래 보관한다.
- 타겟팅 기술 글 작성
    - 특정 대상을 설정하고 그들이 이해할 수 있는 기술 글을 써본다.
    - 글을 쓰다가 막히는 지점이 있다면, 그곳이 바로 아직 완벽히 이해하지 못한 지식의 구멍이다.
    - 알고 있는 것을 적는 게 아니라, 모르는 것을 찾아내기 위해 적는다.
