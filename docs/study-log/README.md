# 학습법

---

## 학습법 v1

- 기본 개념이 부족한 것 같아서 기본 개념서 1권을 읽으면서 미션 병행함
- 미션을 하다가 막히는 부분에서, 뭘 모르고 어떤 걸 찾아야 하는지 몰라서 AI를 통해 학습함
- 그때그때 부족한 걸 채워야 하는데, 처음부터 다 알아야 한다는 마음에 오랫동안 공부함
- 미션이 딜레이됨


## 학습법 v2

#### 1. 시간 관리 → 하버드 1/3 법칙

- 1단계 (전체 시간의 1/3 지점): 기능 구현 90% 완료
- 2단계 (남은 2/3 시간): 지식 보완 및 리팩터링

#### 2. 나선형 학습

1. 미선 시작 전 필수 개념만 훑기 (1~2시간 내로)
2. 구현 시작
3. 막히는 부분이 생길 때까지 미션 수행
4. 막힌 부분에 대해 검색 (AI에게 이 코드의 에러 원인과 관련 공식 문서에서 읽어야하는 부분 알려달라고 하기)
5. 심화 확장: 구글링 → 공식 문서 → 기본서

#### 3. 나중에 내가 읽어도 이해할 수 있는 최소한의 기록법

- 공부한 모든 내용을 적으려 하지 말고 [문제 상황 - 시도한 것 - 해결 방법 - 핵심 키워드]만 기록하기
- 내가 공부한 내용이 전체 기술 스택 중 어디에 위치하는지 마인드맵을 그리기


## 학습법 v3

#### 1. 시간 관리 → 하버드 1/3 법칙

- 1단계 (전체 시간의 1/3 지점): 기능 구현 90% 완료
- 2단계 (남은 2/3 시간): 지식 보완 및 리팩터링

#### 2. 나선형 학습

1. 미선 시작 전 필수 개념만 훑기 (1~2시간 내로)
2. 구현 시작
3. 막히는 부분이 생길 때까지 미션 수행
4. 가볍운 막힘이라면 5분 내로 문제를 해결한 뒤 기술 부채 키워드를 노션에 기록하고 넘어가기
5. 무겁게 막히는 부분이 생기면 15분 타이머를 맞추기
6. 막히는 부분에 대해 구글링 → 핵심 내용 직접 타이핑해서 정리 → AI 에게 검증 요청
7. 15분이 지나면 검색과 정리를 바로 멈추기
8. 해결되지 않은 상태 그대로 [문제 상황 - 시도한 것(15분간의 기록)]을 노션에 짧게 남기고, 하드코딩이나 임시 방편을 써서라도 다음 기능 구현으로 넘어가기 혹은 정리된 내용을 들고 크루에게 질문하기
9. 심화 확장: 구글링 → 공식 문서 → 기본서

#### 3. 나중에 내가 읽어도 이해할 수 있는 최소한의 기록법

- 공부한 모든 내용을 적으려 하지 말고 [문제 상황 - 시도한 것 - 해결 방법 - 핵심 키워드]만 기록하기
- 내가 공부한 내용이 전체 기술 스택 중 어디에 위치하는지 마인드맵을 그리기
