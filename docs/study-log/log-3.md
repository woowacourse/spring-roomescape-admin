### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?

pr 사이클에 맞게 학습 범위를 조절하도록 변경할 예정이다.

- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
```aiexclude
1) 역문제 풀이 학습 적용
    1) 미션(문제 상황)을 먼저 살펴보고 어떤 문제가 발생했는지 확인한다.
    2) 어떤 개념들이 필요할지 학습 목표를 설정한다.

2) 미션을 먼저 진행한다 (실습 → 이론 순서)

3) 실습을 진행하면서 잘 모르거나 해결이 안 되는 문제들을 기록한다.

4) 1차 학습 (PR 전 단계)
    - 코드의 전체 흐름과 각 부분의 역할을 설명할 수 있는 수준을 목표로 한다.
    1) AI를 활용하여 모르는 개념의 전체 흐름을 파악한다. (예: "xx를 5단계로 설명해줘")
    2) 해당 흐름을 기반으로 모르는 부분을 스스로 질문한다.
    3) 해당 질문에 대해 공식문서(Primary Source)를 우선적으로 확인한다.
    4) 공식문서로 이해가 어려운 경우 AI(Secondary Source)를 보조적으로 활용한다.

5) PR 단위 학습 사이클 반복
    1) 1차 사이클: 미션 해결 및 PR 제출
        - 모든 개념을 깊게 이해하기보다, 코드의 역할과 흐름을 설명할 수 있는 수준까지만 학습한다.
    2) 2차 사이클: 핵심 개념 동작 방식 이해
        - 반복적으로 등장하거나 이해를 막았던 개념을 선별하여 동작 원리를 학습한다.
    3) 3차 사이클: 개념의 필요성 이해
        - 해당 개념이 없을 경우 어떤 문제가 발생하는지까지 확장하여 학습한다.

6) 보조 학습 전략
    1) mindmap을 활용하여 학습한 개념을 점진적으로 확장한다.
        - 처음부터 정리하지 않고, PR 사이클을 반복하면서 필요한 개념만 추가한다.

7) 학습 마무리
    - 학습 사이클이 완료된 이후, 학습한 내용을 나만의 언어로 다시 설명한다.
    - (예: 다른 크루에게 설명하거나, 스스로 말로 정리)
```

### 3. 전략 평가
- 효과적이었던 것과 그 이유

3단계 미션에서는 1,2 단계에 비해서 추가적으로 어려웠던 부분은 많이 없어서 공부법을 크게 적용해보지는 못했다.
다만, inner join 코드를 작성할 때 헷갈리는 부분을 공부할 때 처음부터 Deep Dive 하지 않고 전체적인 흐름을 먼저 공부할 수 있었다.

- 비효과적이었던 것과 그 이유

mindmap에 추가하거나 나만의 언어로 설명할 만한 내용이 없어서 이 부분에서는 효과를 보지 못했던 것 같다.

- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?

3단계 미션은 1,2단계의 반복이라고 할 수 있어서 코드나 개념의 어려움은 적었다. 따라서, 이번 전략이 활용될 부분이 적었다.


### 4. AI 피드백

  유용했던 제안 1가지 이상 기록

- 난이도와 관계없이 최소 1개 이상의 개념을 반드시 정리한다.
- mindmap은 새로운 개념이 없더라도 기존 개념 간의 관계(예: join 종류 비교)를 추가하는 방식으로 활용한다.

### 5. 다음 타임에 바꿀 것
- 유지할 것과 그 이유

기존 방식은 모두 그대로 유지할 것이다. 이번 단계는 새로움 어려움을 만났다기 보다는 반복되는 
문제를 만났을 떄 학습 전략을 세우는 것과 비슷했기 때문에 기존 방법은 유지하고 추가적인 방법을 넣을 예정이다.

- 바꿀 것과 그 이유

현재 학습 난이도보다 쉽거나 반복되는 문제를 만날 경우 난이도와 관계없이 최소 1개의 개념을 반드시 정리하고
이를 mindmap에 추가한다. 이는 쉬운 문제라고 해서 학습을 생략할 경우 개념 간 연결이 약해지고, 
장기적으로는 이해의 깊이가 쌓이지 않는 문제가 발생할 수 있기 때문이다. 
따라서 반복되는 상황에서도 최소한의 개념 정리를 통해 지식을 지속적으로 축적하고 확장해 나가려 한다.

- 바꾼다면 왜? 바꾸지 않는다면 왜?

이전 단계에서 설정한 전략은 전체 흐름을 먼저 이해하고 이후에 필요한 부분을 
점진적으로 깊게 학습하는 방식이었으며, 실제로 inner join과 같은 개념을 학습할 때도 이 접근이 효과적으로 작용했다. 
따라서 전략 자체를 바꾸기보다는, 상황에 따라 활용도를 높이는 방향으로 보완하는 것이 더 적절하다고 판단했다.

- 이전 단계에서 발견한 "나에게 맞는 전략"이 새 단계에서도 통할 것 같은가?

또한 이전 단계에서 발견한 나에게 맞는 전략은 새로운 단계에서도 충분히 통할 것으로 보인다. 
특히 실습을 먼저 진행하고 이후에 개념을 정리하는 방식은 학습 효율을 높여주었고, 
막히는 지점을 명확하게 인식하는 데 도움이 되었다. 다만 이번 단계에서 느낀 것처럼 난이도가 낮을 때 
전략 활용이 줄어드는 문제가 있었기 때문에, 이를 보완하여 어떤 난이도에서도 일관되게 전략을 
적용하는 방향으로 개선해 나갈 예정이다.
