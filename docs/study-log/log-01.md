### 2. 이번 타임의 학습 전략
- MVC 1단계에서 필요한 개념을 먼저 문제 기준으로 나눠서 봤다.
- `@ResponseBody`, `@RequestBody`, `@PathVariable`처럼 바로 필요한 요소부터 학습했다.
- 학습 테스트와 미션 테스트를 같이 보면서, 개념을 확인한 뒤 바로 코드에 적용했다.

### 3. 전략 평가
- 효과적이었던 점은 필요한 개념만 먼저 확인하고 바로 구현에 연결한 것이다.
- 이번 막힘은 "코드로 어떻게 쓰는지 모르겠다"는 문제였기 때문에, 예제를 바로 보고 적용하는 방식이 잘 맞았다.

### 4. AI 피드백
- 개념을 한 번에 넓게 보려 하기보다, 현재 문제를 해결하는 최소 개념부터 잡고 확장하라는 피드백이 유용했다.
