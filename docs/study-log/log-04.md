### 1. 막힌 것의 종류
이번에 막힌 것은 어떤 종류의 어려움이었는가? (해당하는 것에 체크)
- [x] 개념 자체를 모르겠다 (예: "스프링 빈이 뭔지 모르겠다")
- [ ] 개념은 알겠는데 코드로 어떻게 쓰는지 모르겠다 (예: "JdbcTemplate 문법을 모르겠다")
- [ ] 코드는 돌아가는데 이게 맞는 건지 모르겠다 (예: "계층 분리를 이렇게 해도 되나?")

### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었는가? <br>
  👉 학습 모드 선택(자료기반 학습 / Problem-Driven 학습) <br>
  판단 기준: 학습 대상의 유형
  - 정답이 정해진 개념/문법: **자료 기반 학습**
  - 정답이 없는 탐구형 학습: **Problem-Driven 학습**
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
  
콘솔 로직에서 컨트롤러로부터 오는 예외를 처리하는 코드를 작성 중이었는데 
문득 스프링에서 사용하던 @RestControllerAdvice 및 @ExceptionHandler가 떠올랐고 내부적으로는 어떤식으로 구현되는지 궁금해져서 학습했다.
이는 정답이 정해진 학습이기 때문에 **자료 기반 학습**을 진행했다.<br>
자료는 김영한 강사님의 강의인 '스프링 MVC 2편' 중 '9. API 예외처리' 부분을 활용했다.
<br> 학습을 마친 뒤, 실제로 내 컨트롤러 코드에 @RestControllerAdvice 및 @ExceptionHandler를 적용했다.
