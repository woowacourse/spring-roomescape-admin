## 버전 별 학습법

### v1

> 여러 레퍼런스를 탐색하여 공통의 best practice를 학습 후, 이를 적용한다.
> 
> 모르거나 막히는 것이 생기면 주변 크루들의 의견을 구하고, 내 생각과 합쳐서 적용해본다.
> 
> 리뷰어의 피드백이 제공되는 학습인 경우, 리뷰어의 피드백을 상세하게 기록한다.
> 
> 마감 시간이 얼마 남지 않은 경우를 제외하고 순수 학습 목적으로는 되도록 AI의 사용을 지양한다.
### v2
> best practice 보다는 **better practice** 를 세우면서 접근, 
근거를 확실하게 세우고 코드 리팩토링처럼 리팩토링을 하며 다듬어나가자

### v3

> 1. AI를 나의 논리를 공격하는 비판자로 설정하여 논쟁
- 누군가에게 가르칠 수 없다면 그것은 제대로 알지 못하는 방증
- 예시: 나는 ~ 개념에 대해 ~라고 이해했는데, 내 논리에서 허점을 찾아서 나를 공격해줘
- 레벨 AI 인터뷰에서 진행한 방식과 유사한 학습법
> 2. 정리를 버리고 설명을 적기
- 내가 이해한 A가 B인 이유는 C 때문이다. 하지만 D라는 상황에서는 어떻게 동작할까?"라는 질문을 작성
> 3. 무지의 지도(Map of Ignorance) 만들기
- 공식 문서를 보며 '이해가 안 가는 용어'와 '충돌하는 개념'만 리스트업
- 지워나가는 과정이 나의 better practice를 찾는 길
