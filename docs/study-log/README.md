## 학습법 변천사

### 학습법 v1
- AI를 활용하되, 단순히 '어떻게 해결할까'를 고민하기보다 '왜 이 기능이 이 위치에 사용되는가?'와 같은 질문을 의식적으로 던지는 연습을 했다.
  내가 지금 무엇을 학습하려는지 명확히 인지한 상태에서 AI와 대화하는 것이 학습에 더 도움이 된다고 판단했다.

### 학습법 v2
- 단순히 ‘왜?’라는 질문을 던지는 것만으로는 학습에 한계가 있다는 생각이 들었다. 
크루들과 학습 과정을 공유하며 의견을 나누어 보니, 단순히 작동 방식을 이해하는 것보다 내가 어떤 식으로 문제에 접근하려 했는지, 그리고 이 기능이 현재 학습 단계에서 꼭 필요한 것인지를 고민하며 학습하는 것이 더 낫다는 판단을 했다. 
무엇을 배우는지 명확히 인지하지 못한 채 구현에만 집중하기보다, 접근 방식의 타당함과 기능의 필요성을 스스로 점검하며 학습하는 태도가 필요하다는 것을 인지하였다.

### 학습법 v3
- AI가 제시한 방법을 무조건적으로 수용하고 적용하는 것을 제한하는 학습법을 세웠다. AI가 제안한 방식이 현재 미션의 설계 의도와 학습 단계에 정말 필요한 것인지 스스로 검증하는 절차가 필요하다고 생각해사 해당 학습법을 계획했다.
