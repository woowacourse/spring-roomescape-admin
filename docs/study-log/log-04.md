### 1. 막힌 것의 종류
이번에 막힌 것은 어떤 종류의 어려움이었는가? (해당하는 것에 체크)
- [ ] 개념 자체를 모르겠다 (예: "스프링 빈이 뭔지 모르겠다")
- [ ] 개념은 알겠는데 코드로 어떻게 쓰는지 모르겠다 (예: "JdbcTemplate 문법을 모르겠다")
- [ ] 코드는 돌아가는데 이게 맞는 건지 모르겠다 (예: "계층 분리를 이렇게 해도 되나?")
- [x] 기타: 4단계는 비교적 수월하게 진행되었습니다.

### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
  - 3단계의 학습전략을 그대로 진행하였습니다.
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
    ```
    4단계를 진행하기에 앞서, 4단계 참고 자료에 있는 학습 테스트를 먼저 진행했습니다.
  
    이전 단계와 동일하게 문제해결용 멘탈 모델 카드 5개를 AI를 통해 학습을 하였고, 
    추가적으로 퀴즈를 통해 검증받는 방식으로 학습했습니다.
    
    퀴즈를 생성하는 템플릿은 아래와 같습니다.

    1. 총 5문제 이하로 만들어줘.
    2. 단순 암기 문제가 아니라, 실제 구현 상황에서 판단해야 하는 문제로 만들어줘.
    3. 문제 유형은 아래 비율로 구성해줘.

      - 개념 확인 1문제
      - 동작 흐름 1문제
      - 코드 적용 1문제
      - 실수/주의점 1문제
      - 실제 문제 상황 판단 1문제

    4. 정답은 바로 보여주지 말고, 내가 먼저 풀 수 있도록 문제만 먼저 보여줘.
    5. 내가 답을 제출하면, 그때 채점하고 틀린 이유와 다시 봐야 할 핵심만 설명해줘.
  
    4단계에서는 계층 분리가 핵심이었는데, 학습 테스트와 학습 전략을 1,2,3단계에 잘 적용하면서
    진행해와서 그런지 service 계층만 추가하면 요구사항이 만족되었습니다.
    부족한 부분에 대해서는 추후에 리팩토링 할 예정입니다.
    ```

- 비효과적이었던 것과 그 이유

  - 4단계는 수월하게 진행되어서 궁합을 측정하기에는 애매하다고 생각합니다.
