## 학습법 V1
```text
1. 페어프로그래밍을 할 때에 의견이 안맞는 지점이 있다면 ‘시간 안에 완성할 수 있는가’, ‘현재 구현 상황에 단점이나 장점이 명확하지 않은가’를 기준으로 합의 하에 구현 방법을 선택한다.
2. 해당 부분을 pr본문에 작성하고 리뷰어의 의견을 들으며 생각을 정립해 나간다.
3. 개인이 코드를 작성할 때에는 AI와의 대화를 활용한다. 다른 관점이 궁금해진다면 크루들과 대화를 해본다.
```

## 학습법 V2

## 학습법 V3
> 아는 것에 안주하지 않고 모르는 것이 어떤 것이 있을지 주도적으로 찾아본다.
```text
1. 사실 기반 질의응답을 ai와 할때 방법은 다음을 따른다.
- 5분~10분 단위로 맥락을 정리하는 시간을 갖는다.
  - 대화를 한 문장으로 요약해서 AI에게 다시 던진다. AI가 “맞다“고 하면 그때 다음 노드로 이동한다.
- AI에게 질문할 때 트리구조를 시각화하며 진행한다. 5분~10분 맥락이 종료되었을때, 2depth 초과로 노드가 깊어졌다면, 상위노드로 우선 복귀하고 질문을 하며 처음 목표에 관한 의문을 해소한다. 추가적인 질문은 다른 곳에 작성해두고 하나의 의문이 해소되었을 때 진행한다.

2. 활용에 관한 의견은 여러 사람의 의견을 직접 들어본다.
```
