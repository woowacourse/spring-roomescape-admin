## 학습법 변천

#### v1. 직접 부딪히는 경험 중심 학습

방식: 선 구현 후 개선, 실패→성공 루트의 직접 경험 중시

특징: 정답을 먼저 보기보다 스스로 해결할 때까지 AI와 끝장 토론을 하며 지엽적인 부분까지 파고듦

한계: 깊이에 매몰되어 넓이(전반적인 필수 지식)를 챙기지 못하는 문제 발생

#### v2. 리소스 활용과 속도전

방식: 빠른 완성 후 PR을 목표로 리소스(AI, 피드백) 적극 활용

특징: 무엇이 중요한지 스스로 판단하지 않고 AI/피드백에 의존하여 투자 시간 결정. 단순 호기심(예: Gradle 내부 동작)은 과감히 생략

변화: 직접 경험만 고집하던 도구 제약을 풀고, 효율적인 도구 활용으로 전환

#### v3. 질문 기반 인출과 기술 대조 (전략적 고도화)

방식: 효율을 유지하되, 학습의 질을 높이는 질문 목록과 과거와의 대조 추가

방법론: 학습한 중요 내용에 대해 질문 리스트를 만들어 다음 날 스스로 답변(장기 기억화), 실패 시 재학습
