## V1
- 초기 학습 단계에서 교재/강의의 핵심 개념만 선별적으로 습득
- AI 및 웹 서칭 기반 키워드 중심 탐색으로 지식 범위 확장
- 학습 내용을 즉시 코드로 구현하며 실습 중심으로 검증
- AI와의 반복적인 토론을 통해 개념을 구체화하고 이해도를 심화

## V2
- 구글링으로 사용법과 개념 러프하게 파악
- 파악한 내용으로 AI와 토론
- 공식 문서 / 여러 블로그에서 ai와 토론한 내용을 교차 검증
- 학습 내용을 즉시 코드로 구현하며 실습 중심으로 검증
- 학습된 내용을 문서로 정리

## V3
- 해결할 문제/장애 상황 먼저 설정
- 관련 기술 러프하게 탐색 (구글링, 공식문서, 사례)
- AI와 토론하며 해결 방향 가설 수립
- 가설 기반 기술 사용법 학습 (퀵스타트, 핵심 개념, 주요 API, 최소 예제)
- 공식 문서/블로그로 가설 + 사용법 + 적용 방식 교차 검증
- 가능하면 새프로젝트를 만들기 보다. 기존 프로젝트에 적용하며 개선
- 학습 문서화 (가설 → 선택 이유 → 사용법 → 결과 → 재사용(대안 비교) 기준)
- 다음 문제에 반복 적용하며 고도화
