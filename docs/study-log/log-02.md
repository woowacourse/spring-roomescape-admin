### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
  - 단순한 접근으로 구현 후 피드백 받기 실행했다.
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
  1. 단순하게 구현하기: 요구사항에 나와있는 것처럼 객체 저장을 컬렉션에서 JdbcTemplate으로 수정했다.
  2. 다음 단계에 대한 심화 피드백 받기: 1단계에서 이미 다 진행했던 내용이라 얻은게 없었다.
  3. 학습법 V3 적용 - 가설 기반 질문: 계층 간 DTO의 필요성을 전달하기 위해 DB_조회_API_전환에서 도메인 객체로 직렬화하는 테스트 코드가 존재한다.
     * 피드백에서는 막힌 부분이 없었지만, 테스트 코드에서 실패하는 코드가 하나 있었기 때문에 해당 내용으로 V3를 적용했다.
     * Cannot construct instance of `roomescape.domain.Reservation` (no Creators, like default constructor, exist): cannot deserialize from Object value (no delegate- or property-based Creator)
     * 잭슨 라이브러리에서 위와 같은 예외가 터져서 Reservation 객체로 직렬화 할 수 없다는 것을 알게 됐다.
     * 하지만 웹 계층에서 정상동작하는지 테스트를 하려면 응답된 결과를 Reservation으로 변환해서 유효한 정보를 전달받았는지 확인하는 방법이 있다.
     * 하지만 Jackson의 동작 방식으로 인해 Reservation에 기본 생성자 혹은 JasonCreator 어노테이션이 붙은 생성자가 필요하다.
     * 결국 웹 계층의 테스트를 위해 Domain Model이 오염된다. 그래서 데이터만을 전달하는 책임을 분리해서 도메인을 보호할 수 있다.
  4. 자원 확장 및 심화: 가설에 대해 긍정적인 답변을 받았지만, 충분한 근거를 얻고 싶어서 관련 정보를 요청했다.
     * 1단계에서 적용했을 때 현재 답변과 같은 답변을 받았다.
  5. 장난감 모델 검증 및 피드백: 가설이 옳은지 확인하기 위해 테스트 코드를 Dto로 변경해봤다.
     ```java
        // 기존 코드
        List<Reservation> reservations = RestAssured.given().log().all()
                .when().get("/reservations")
                .then().log().all()
                .statusCode(200).extract()
                .jsonPath().getList(".", Reservation.class);

        // 수정 후 코드
        List<ReservationResponse> reservations = RestAssured.given().log().all()
                .when().get("/reservations")
                .then().log().all()
                .statusCode(200).extract()
                .jsonPath().getList(".", ReservationResponse.class);
     ```
     * 정의한 가설대로 웹 테스트 코드의 응답을 Dto로 변경했을 때, 도메인을 보호할 수 있었다.
