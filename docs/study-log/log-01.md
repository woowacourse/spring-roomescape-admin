- [ ] 개념 자체를 모르겠다 (예: "스프링 빈이 뭔지 모르겠다")

- [ ] 코드는 돌아가는데 이게 맞는 건지 모르겠다 (예: "계층 분리를 이렇게 해도 되나?")

### 2. 이번 타임의 학습 전략

- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
  log1이기 때문에 이전에 바꾸기로 한 전략이 없다.

- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.

1. 미션 요구사항 읽기
2. 먼저 구현해야할 것으로 예상되는 기능 확인: 예약 추가 기능
3. 해당 기능 구현에 필요한 지식이 없음을 확인
4. 기능 구현에 필요한 지식을 습득할 때 까지 미션에서 제공한 <스프링 학습 테스트>를 따라 최소한 학습
5. 학습 테스트의 예시 코드를 기반으로 기능 구현

### 3. 전략 평가

- 효과적이었던 것과 그 이유
  기능을 빠르게 구현할 수 있었다.

- 비효과적이었던 것과 그 이유
  학습하며 본 예제 코드를 기계적으로 적용했기에, 작성된 코드에 대해 매우 얕게만 이해하는 상태

- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?
  미션에서 제공된 학습 자료를 통해 진행되었기에, 기반 지식이 없는 것 치고는 빠르게 기능을 구현했다고 생각한다.

### 4. AI 피드백

- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고,
  유용했던 제안 1가지 이상 기록

AI 피드백 요약
제공된 학습 테스트를 활용해서 빠르게 진입했다는 것은 나쁘지 않음.
다만, 학습 테스트가 예시 코드가 아닌 정답지가 되어버림.

개선 제안
예시를 학습한 이후 예시를 보지 않고 혼자서 코드 작성을 다시 시도할 것.

### 5. 다음 타임에 바꿀 것

- 유지할 것과 그 이유

  학습 테스트를 이용한 학습은 유지할 것이다.

  모르는 것이 훨씬 많은 상황에서 혼자서 개념을 고민하거나 유추하는 것은 비효율적이라고 판단했다.
  제대로 된 추론이 아닌 추측에 가까워 틀린 방향성으로 고민하게 된다고 생각하기 때문

  학습 테스트의 예시 코드를 기반으로 구현한 기능은 테스트 통과 이후
  AI가 제시한대로 다시 한 번 작성해보는 과정을 추가할 것이다.
