**시간**: MM/DD HH:MM ~ HH:MM (약 __분)
**학습 범위**: 4단계 계층 분리

### 단계 전환 체크
- 이전 단계에서 쓴 접근법을 그대로 쓸 것인가, 바꿔볼 것인가?
  - Output에 학습한 패턴(규칙) 기록 작성을 추가해볼 예정입니다.
- 바꾼다면 왜? 바꾸지 않는다면 왜?
  - 막히는 부분이 많이 생겼을 경우, 학습할 것들을 계속해서 남겨만 두고 있어서 패턴으로 남기는 작업을 추가하면
    실제로 다음 번에 실행 가능한 규칙이 생겨 효과적일 것 같습니다.
- 이전 단계에서 발견한 "나에게 맞는 전략"이 새 단계에서도 통할 것 같은가?
  - 계속 유효했다고 생각이 들고, 앞으로도 그럴 것 같습니다.

### 1. 막힌 것의 종류

- [ ] 개념 자체를 모르겠다 (예: "스프링 빈이 뭔지 모르겠다")

- [ ] 코드는 돌아가는데 이게 맞는 건지 모르겠다 (예: "계층 분리를 이렇게 해도 되나?")
