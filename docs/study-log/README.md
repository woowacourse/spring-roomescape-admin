# 학습 방법론

---

## v1 — 기본 학습 흐름

### 개념 학습
처음 접하는 개념은 책이나 강의로 전체 흐름을 먼저 파악한다.
이후 이해가 안 되는 부분이 생기면 AI를 활용해 해당 내용을 보충 학습한다.

### 코드 작성
바로 구현해야 하는 상황에서는 일단 코드를 작성한 뒤, 그 코드가 나온 이유를 스스로 되짚어본다.
코드가 올바르지 않다면 리팩토링을 진행하고, 부족한 부분은 AI나 블로그를 참고해 채운다.

## v2 — 목적 중심 학습

> JVM 학습을 계기로 적용한 방법. 깊이보다 방향을 우선한다.

- **선 이해 후 기록**
- **학습 목적 리마인드**
    - 지금 당장 필요한 것만 학습한다.
    - 학습 목적을 리마인드하며 한 번에 하나씩, 해소되면 더 이상 깊이 파지 않는다.
- **다음 학습에서 deep dive**

## v3 — 단계별 심화 루틴

### 1. 시작 전: 왜 배우는가 한 줄 정의

학습을 시작하기 전, 목적을 한 줄로 적는다.

```
예: "JVM을 배우는 이유 → 자바 코드가 OS 상관없이 실행되는 원리를 이해하기 위해"
```

방향을 잃었을 때 돌아올 기준이 된다. 이 목적에서 벗어난 내용은 깊이 파지 않는다.

---

### 2. 선 이해

지금 당장 필요한 것만 학습한다.
한 번에 하나씩, 해소되면 더 이상 깊이 파지 않는다.
(이 과정에서 AI, 강의, 유튜브, 블로그, 책 모든 것을 사용해도 된다.)
---

### 3. 말해보기

코딩하면서 지금 하고 있는 것을 말로 중계한다.
막히는 순간 말이 끊기는데, 그 지점이 이해의 빈틈이다.

> 말로 설명하지 못하는 것은, 사실 이해하지 못한 것이다.
> "어... 이게... 음..." 하고 막히는 순간이 바로 진짜 이해의 빈틈이다.

---

### 4. 해소 기준 확인

넘어가기 전, 아래 문장을 채운다.

```
___는 ___때문에 ___방식으로 동작한다. 그래서 ___상황에서 의미가 있다.
```

- 채워지면 기록하고 넘어간다.
- 막히는 칸이 있으면, 그게 다음 deep dive의 시작점이다.

---

### 5. 기록: 기존 지식과 연결

해소 기준 문장과 함께, 이미 아는 개념과 어떻게 이어지는지 한 줄을 덧붙인다.

```
예: "JVM 클래스로더 → 이전에 배운 import 동작 원리와 연결됨"
```

연결이 쌓이면 조각이 아닌 구조로 이해가 자리잡는다.

---

### 6. 다음 학습에서 deep dive

해소 기준에서 막힌 칸, 또는 연결하다 궁금해진 것을 다음 학습의 시작점으로 삼는다.
