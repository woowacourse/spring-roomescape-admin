### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?


- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
1. 집중할 하나의 필수개념을 정의하고, 내가 아는 것을 작성하며 내 상황을 체크한다.
2. AI에 과제와 1번 내용을 넣고 3가지 질문을 추천해달라고 요청한다.
3. 공식문서를 참고해서 질문에 대한 답을 스스로 작성한다.
4. 답을 GPT에게 넣고 틀린 부분이 있는지 검토받는다.   
  이때, 맞은 건 패쓰하고, 틀린 부분은 다시 생각해볼 수 있도록 질문해달라고 프롬프팅 했다.
5. 3번과 4번을 30분 동안 반복하고, 30분이 초과했는데 안끝난 질문은 GPT에게 개념 설명을 요청한다.
6. 코드 구현하며, 위에서 학습했던 개념과 연결지어본다.

### 3. 전략 평가
- 효과적이었던 것과 그 이유    
AI와 피드백을 주고 받을 때, 메인 질문 3가지에 벗어난 내용이면 배제하고,      
관련된 내용이면 연관지어서 서브 질문으로 연결해두니 이해가 쉬웠습니다.


- 비효과적이었던 것과 그 이유    
GPT에게 단순히 개념 설명을 듣는 과정은 비효과적이었습니다.    
개념설명을 들은 후 스스로 돌아볼 시간을 추가하면 좋을 것 같습니다.


- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?
어느 정도 효과적이긴 했지만, 지금의 전략은 개념을 모르거나 개념을 아는데 코드 구현을 못하는 경우에 더 적합한 것 같습니다.
코드는 돌아가는데, 맞는 건지 모르겠다는 코드 구현한 사항을 AI에 넣어서 피드백 받는 방법이 더 효과적일 것 같습니다.

### 4. AI 피드백
- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고, 유용했던 제안 1가지 이상 기록
"닫힌 상태 회상만 추가하면 훨씬 더 강해집니다."

### 5. 다음 타임에 바꿀 것
- 유지할 것과 그 이유
공식문서를 바탕으로 공부하는 것은 유지할 것 입니다.
개념에 대해 객관적으로 공부할 수 있고, 연관 개념이나 키워드를 파악하기도 수월하기 때문입니다.

- 바꿀 것과 그 이유    
만약 개념에 대해서 알고 있는 상태라 하면 지금의 학습법에서 개념 학습의 시간을 줄이고, 
코드에 대한 피드백을 받는 시간을 더 확보할 것입니다.
