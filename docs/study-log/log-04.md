### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?
  - AI를 통해 알게 된 코드는 반드시 다시 다 지우고 처음부터 내 손으로 직접 다시 해보기를 실행하지 않았습니다. AI를 통해서 알게 된 코드가 없었고 제가 스스로 계층을 분리했습니다.
- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
  - 이전 단계들에서 이미 계층 분리의 필요성을 느끼고 선제적으로 구조를 잡아두었습니다. 이번 단계에서는 새로운 학습보다는 기존 구조를 정교화하고 계층 간 데이터 흐름을 점검하는 데 시간을 썼습니다.

- 솔직히 전략평가를 할 수 없었습니다. 이미 거의 계층 분리가 완벽했고 따로 공부를 뭘 해야할지 몰라서 모르겠습니다. 저딴에는 계층분리가 순조롭게 흘러갔고 막힌 부분이 없었습니다.

### 5. 다음 타임에 바꿀 것
- 유지할 것과 그 이유
  - 먼저 목표를 잡고 모르는 개념이 있으면 AI를 통해 1차로 공부를 합니다. 그리고 목표를 벗어나는 주제는 일단 키워드로 메모해놓고 공부를 목표까지 합니다.
    바로 코드를 작성하며 몸으로 느껴봅니다. 그리고 코드를 작성하며 모르는 부분이 생겨 AI를 통해 코드를 알게 되었다면 한번 전체적으로 지워서 다시 제가 직접 작성해보며 몸으로 익힙니다. 
    저는 이 방식을 유지할 것입니다. 혼자 학습하는 것 중에서 저한테 효율이 가장 좋았던 것 같습니다.
