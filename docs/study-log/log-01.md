#### 🧪 RestAssured
* 복잡한 HTTP 요청/응답 검증을 영어 문장처럼 직관적으로 작성하는 도구.
* **핵심 구조**: `given(준비)` -> `when(액션)` -> `then(결과)`
```java
@Test
void 예약_조회() {
    RestAssured.given().log().all()
            .when().get("/reservations")
            .then().log().all()
            .statusCode(200)
            .body("size()", is(0)); 
}
```

#### 🏗️ 로직 설계 방식 (TDD 전략)
* **Outside-In (하향식)**: API 스펙 먼저 정의. 사용자 요구사항에 집중하며 불필요한 기능을 방지함.
* **Inside-Out (상향식)**: 도메인 모델 먼저 설계. 핵심 비즈니스 로직을 견고하게 다질 수 있음.

* **DTO**: `String` 사용 (통신 편의성).
