### 4. AI 피드백
- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고,
  유용했던 제안 1가지 이상 기록
```
AI의 설명을 듣고 코드를 적용하는 과정은 잘 이루어졌지만, 그 사이에서 “내 언어로 개념을 재구성하는 단계”가 빠져 있습니다.
현재의 흐름은 AI로부터 설명을 입력받고, 그것을 바탕으로 코드를 작성해 테스트를 통과시키는 구조입니다.
이 방식은 빠르게 학습 범위를 넓히는 데는 효과적이지만, 실제로는 개념을 깊이 있게 이해하지 못한 채 넘어갈 가능성이 큽니다.

학습법 v3에 딱 하나의 개선만 추가한다면, “설명 강제 단계”를 넣는 것을 강하게 권장합니다.
구체적으로는, AI로부터 개념 설명을 들은 직후 바로 코드를 작성하는 것이 아니라, 먼저 해당 개념을 문서를 보지 않고 자신의 언어로 정리해보는 것입니다.
예를 들어 @PostMapping을 학습했다면,
“@PostMapping은 HTTP POST 요청을 특정 메서드에 연결해주는 어노테이션이다.주로 데이터를 생성할 때 사용된다”와 같이 스스로 설명해보는 단계가 필요합니다.
그리고 코드를 작성하고 테스트를 통과한 뒤에도 다시 한 번 “왜 이 어노테이션을 사용했는지”, “왜 GET이 아니라 POST인지”를 스스로 설명해보는 것이 중요합니다.

결론적으로, 지금의 학습법은 이미 좋은 방향에 있습니다. 다만 AI를 활용한 빠른 탐색 위주의 학습에서 한 단계 더 나아가기 위해서는,
“코드를 쓰기 전에 설명하고, 코드를 쓴 후에도 다시 설명하는 습관”을 반드시 추가해야 합니다.
```
