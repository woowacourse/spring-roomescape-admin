### 4. AI 피드백
- 자신의 학습 전략에 대해 AI 학습 전문가에게 피드백을 요청하고,
#### 사용한 프롬프트
```text

[지침]
새로운 고민이 생겨 이를 해결하기위해 학습했습니다. 이때, [맥락]에 적혀있는 학습 전략을 사용했습니다.
해당 학습 전략의 장점과 단점 3가지씩 언급해주고
학습 효과를 올리기 위해서 어떤 방법을 시도하면 좋을 지 2가지 이상의 피드백을 부탁드립니다.
답변을 바로 하지말고 해당 답변을 스스로 2번정도 검토한 뒤 답변 부탁드립니다.
이해가 안되는 내용이 있다면, 바로 답변을 중단하고 저에게 다시 물어봐주세요. 

[역할]
당신은 리처드 파인만 입니다. 학습, 교육에 전문성이 있습니다.

[맥락]
학습 로그 템플릿 1~3 전달

```

- 유용했던 제안 1가지 이상 기록
#### 단점
> 실험은 했지만 비교 기준은 조금 부족했다.

```text
# ai 답변

이번 비교 기준은 주로
응답 body가 같은가?
headers가 같은가?
코드가 어떻게 다른가?
였던 것 같습니다.

그런데 ResponseEntity를 제대로 이해하려면 비교 기준을 더 넓혀야 합니다.
예를 들어:

상태 코드를 바꿔보면 어떤가?
body 없이 응답하면 어떤가?
Location 헤더를 넣어보면 어떤가?
실패 응답을 표현할 때는 어떤가?
컨트롤러 코드의 의도가 더 명확해지는가?

즉, 지금 전략은 “정상 응답 비교”에는 좋지만, 경계 상황과 의도 표현을 비교하기에는 부족했습니다.
```

#### 피드백
- 차이가 잘 드러나는 실험 케이스를 일부러 만들어봐라.
- 기술의 필요성은 평범한 상황이 아니라, 불편한 상황에서 드러난다.
- 공식 문서를 읽기 전에 문서에 던질 질문을 정해봐라. -> 글을 읽을 때, 호기심을 가지면서 주도적으로 읽으라는 뜻 같다.
- 마지막 정리에서 한 문장 결론을 꼭 적어봐라.
