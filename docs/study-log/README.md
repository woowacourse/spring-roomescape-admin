# 방탈출 예약 관리

## 학습법 변천


### v1 학습법
1. 문제를 풀다가 설계가 막히면 AI에게 설계를 맡기고 AI의 답변을 듣고 이해한다.
> 이 설계가 왜 이런식으로 나온건지 충분히 고민을 해보지 못한 부분이어서 다음에 비슷한 문제가 나왔을 때 적용이 가능할만큼 학습이 제대로 되지는 않았던 것 같다.
2. 완벽한 설계가 떠오르지 않더라도, 일단 돌아가는 코드를 구현을 하고, 어떻게 개선을 시켜야할지 충분히 고민을 해보고, 그래도 모르겠으면 AI한테 물어본다.
> 어느부분에서 고민이 되었는지도 명확하게 알 수 있었고 머릿속에 깊게 남았다.

---

### v2 학습법
Feedback Loop을 사용하되, 두가지 기준을 나눈다.
1. 문제를 보고 개념적으로 아예 모르는 내용이 나온다 → 필요한 최소한의 학습을 진행하고 바로 Feedback Loop을 적용한다. (최소한의 학습은 ‘내가 이 개념을 설명할 수 있다’가 기준이다.)
2. 문제를 보고 즉시 풀 수 있는 정도다 -> 학습 없이 즉시 Feedback Loop을 적용한다.

---

### v3 학습법

1. 문제를 본다.
2. 개념적으로 아예 모르는 내용이 나온다.
3. 바로 깊게 공부하지 말고, 문제 해결용 멘탈 모델 카드 5개를 채운다.
    - 이 개념은 무엇인가?
    - 왜 필요한가?
    - 어떤 흐름으로 동작하는가?
    - 지금 문제에서 어디에 적용되는가?
    - 자주 터지는 실수나 주의점은 무엇인가?
4. 5개가 채워지면 학습을 멈추고 바로 구현한다.
5. 구현 중 실패하면, 실패한 부분만 다시 학습한다.
