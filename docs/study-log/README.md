# 학습법

## 학습법 v1
레벨 1에서 진행한 학습법입니다.
```angular2html
[공통 강의 - 웹]
1. LMS 자료를 통한 개념 학습
2. Gemini의 '가이드 학습' 기능을 활용하여 설명 및 내용 확인
3. 온보딩 조원에게 학습한 내용 공유

[미션 진행 중]
1. AI를 활용하여 궁금한 점이나 추가 학습 진행
2. 단순 이해를 방지하기 위한 꼬리 질문
   -> 아쉬운 점 : 장기 기억으로 이어지지 않아 금방 잊어버렸다.

[Enum 사용 목적]
1. Enum 클래스 코드와 JavaDoc 확인
2. Gemini를 활용한 영어 문서 번역
3. 문서를 보며 생각한 점과 궁금한 점을 정리하고 AI를 활용하여 추가 학습
4. 학습한 내용을 노션에 정리
5. 온보딩 조원들과 미니 테코톡 진행하여 학습한 내용 공유
   -> 아쉬운 점 : 학습에 많은 시간이 소요됐다.

[방어적 복사]
1. 개인 블로그 자료 확인
2. AI를 활용한 관련 개념 학습
   -> 아쉬운 점: 단순 이해에서 끝나다보니 기억에 남는 것이 없었다.
```

## 학습법 v2
토론 활동 중 개인 학습에서 진행한 학습법입니다.   
개인 학습에서는 스프링 학습 테스트의 `mvc-2`의 `create`를 학습했습니다.
```angular2html
[학습법 v2]
1. 공식 문서 기반 학습 (AI 활용하여 번역)
2. 코드 작성 및 실습
3. 노션 정리
4. 정리하며 생기는 궁금증, 추가 학습이 필요한 부분은 AI를 활용해 궁금한 점이나 추가 학습 진행 후 기록
5. 주변 크루들에게 설명

[회고]
create를 학습하며 RequestBody를 학습했습니다. 
학습 도중 RequestBody와 연관된 `HttpMessageConverter`와 같이 추가적으로 공부하고 싶은 부분이 생겼습니다.
"공식문서 번역 → 학습 → 실습 → 노션 정리 → 설명"의 과정으로 진행되기 때문에 비교적 많은 시간이 소요된다고 생각됩니다.
또한, 주변 크루들에게 설명할 여건이 되지 않을 땐 어떻게 대체하여 진행할 수 있을지 대안이 필요할 것 같습니다.
```

## 학습법 v3
토론 활동을 통해 마무리한 학습법입니다.
```angular2html
[학습법 v3]
1. 공식 문서 기반 학습 (AI 활용하여 번역)
2. 코드 작성을 위한 최소한의 지식 학습
3. 코드 작성 및 실습
4. 노션 정리 (시간을 정해두고, 15 ~ 30분)
5. 정리하며 생기는 궁금한 점, 추가 학습이 필요한 점은 따로 기록
6. AI를 활용해 궁금한 점이나 추가 학습 진행 후 노션 기록
7. 주변 크루들에게 설명 혹은 15분 안에 학습 가능한 짤막한 가이드 작성 및 말로 설명

[학습법 v3 설명]
공식 문서를 기반으로 학습합니다.
공식 문서는 보통 영어로 작성되어있기에 문서를 AI를 활용하여 번역합니다.

번역된 내용을 바탕으로 필요한 지식을 학습하고 코드 작성이 필요한 지식인 경우 코드를 작성해봅니다.
이때, 코드를 작성할 수 있을 정도로만 학습하고 바로 실습합니다.

코드 작성 및 실습 후에는 학습한 내용을 노션에 정리합니다.
노션에 정리하는 시간은 30분으로 제한합니다. (시간을 정해두고 정리하기, 키워드 위주, 궁금했던 점 위주)

정리하며 잘 모르겠다고 느껴지는 부분이나 궁금한 점이 생기면 AI를 활용하여 관련 내용에 대한 학습을 진행합니다.

이후 주변 크루들에게 설명할 기회가 주어진다면 학습한 내용을 설명합니다.
여건이 되지 않을 경우 해당 지식을 처음 접하는 크루가 15분안에 학습할 수 있을만한 짤막한 가이드를 작성하고 말로 설명해봅니다.
```

### 주말에 시도할 것: 미션 재구현을 통한 나선형 학습

적용 시나리오:
1. [언제·어떤 상황에서 적용할 것인가]
    > 금요일 오후, 기존 코드를 전부 삭제하고 미션을 다시 구현합니다.

2. [그다음 단계는 무엇인가]
    > 구현 중 막히면 2분의 고민 시간을 가진 뒤 이전에 작성했던 노션 기록을 확인 순서로 스스로 해결해 봅니다.
   > 그래도 해결되지 않으면 AI에게 정답 대신 '학습 키워드'를 요청해 해당 개념을 깊게 공부한 뒤 다시 코드를 작성합니다.

3. [멈출 조건 — 어떤 신호가 보이면 바꾸거나 중단할 것인가]
    > 특정 키워드 하나를 파고드는 시간이 30분을 넘어가거나, 당장 미션의 구조를 잡는 것과 상관없는 것 같다는 생각이 들면 중단하고 다시 구현으로 돌아옵니다.
