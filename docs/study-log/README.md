
# V1
```
레벨1에서는 문제를 만나면 먼저 짧은 시간 안에 저만의 생각으로 문제를 해석하고, 가능한 해결 방향을 빠르게 정리한 뒤 AI를 활용해 검증하는 방식으로 학습해왔습니다. 
이 과정에서 단순히 정답을 얻기보다는, 제가 세운 가설이 맞는지 확인하고 더 나은 접근이 있는지를 탐색하는 데 초점을 두었습니다.

AI를 활용하면서 가장 크게 느낀 점은 학습 속도와 정보 접근성이었습니다. 
짧은 시간 안에 다양한 개념과 사례를 접할 수 있었고, 특히 제가 미처 떠올리지 못했던 연관 개념까지 함께 학습할 수 있어 전체적인 시야를 넓히는 데 큰 도움이 되었습니다. 
예를 들어 하나의 문제를 해결하는 과정에서도 단순 구현을 넘어 설계 방식, 패턴, 예외 처리까지 함께 고려하게 되었습니다.
또한 저는 전체를 구조화하여 학습하는 방식을 선호하기 때문에, 개별 개념을 배우더라도 항상 “이 개념이 전체 시스템에서 어떤 역할을 하는가”를 기준으로 정리하려고 노력했습니다. 
이를 통해 단편적인 지식이 아니라 연결된 구조로 이해하고자 했습니다.

결과적으로 저는 “빠른 가설 설정 → AI를 통한 확장 및 검증 → 구조화”의 사이클로 학습을 진행해왔습니다.

```


# V2
```
레벨1에서는 문제를 만나면 먼저 짧은 시간 안에 저만의 생각으로 문제를 해석하고, 가능한 해결 방향을 빠르게 정리한 뒤 AI를 활용해 검증하는 방식으로 학습해왔습니다.
다만 이 과정에서 속도에 치우치다 보니 개념의 본질이나 등장 배경까지 깊게 고민하지 못하는 경우도 있었습니다.

그래서 이후에는 단순히 해결 방법을 찾는 것을 넘어서, “이 개념이 왜 필요한가”, “어떤 문제를 해결하기 위해 등장했는가”를 먼저 고민하는 방향으로 학습 방식을 보완하고자 했습니다. 
문제 상황을 출발점으로 삼고, 관련 자료를 찾아보며 제 나름의 가설을 세운 뒤 AI를 통해 이를 검증하는 흐름으로 점차 발전시켰습니다.
AI는 여전히 중요한 도구였지만, 이전처럼 빠르게 답을 확인하는 용도보다는 제가 세운 가설을 점검하고 더 넓은 관점을 얻기 위한 보조 수단으로 활용하려고 의식했습니다. 
이를 통해 단순한 정답 중심의 학습에서 벗어나, 사고 과정을 중심으로 학습하려는 변화를 시도했습니다.
또한 저는 전체를 구조화하여 이해하는 방식을 선호하기 때문에, 개별 개념을 배우더라도 서로 어떤 관계를 가지는지 연결하려고 노력했습니다. 
이를 통해 단편적인 지식이 아니라 하나의 흐름으로 이어지는 이해를 만들고자 했습니다.

아직 완전히 정립된 방식은 아니지만, 기존의 “빠른 가설 설정 → AI 검증” 중심에서 “문제 정의 → 가설 설정 → 검증 → 구조화”로 학습 사이클을 점진적으로 발전시키고 있습니다.
```


# V3

```
먼저 문제 상황이나 궁금증을 출발점으로 설정하여, 해당 개념이 실제로 어떤 문제를 해결하기 위해 등장했는지를 기준으로 학습을 시작하겠습니다. 
이후 구글링을 통한 기술 블로그를 중심으로 자료를 탐색하고 정독하며 개념의 정의와 사용 맥락을 파악하겠습니다. 
이 과정에서 바로 정답에 의존하지 않고, “왜 필요한가”, “어떤 상황에서 사용되는가”에 대해 저만의 가설을 먼저 정리하겠습니다.

다음으로, 제가 정리한 가설을 바탕으로 AI를 활용하여 이해를 검증하고 확장하겠습니다. 
이때 AI는 단순히 정답을 얻기 위한 도구가 아니라, 제 사고를 보완하고 더 나은 접근을 탐색하기 위한 피드백 도구로 활용하겠습니다.

이후 학습한 내용은 옵시디언에 핵심 개념과 연결 관계 중심으로 정리하여, 개별 지식이 아닌 전체 구조 속에서 이해할 수 있도록 축적하겠습니다. 
또한 이 과정에서 현재 수준보다 한 단계 높은 개념까지 함께 연결하여 학습 범위를 확장하겠습니다.

일정량의 학습이 축적되면 블로그 글을 작성하여 개념을 재구성하겠습니다. 
이때 단순한 개념 정리를 넘어, “왜 이 개념이 필요한지”, “어떤 상황에서 어떤 선택을 해야 하는지”까지 설명 가능한 수준으로 정리하겠습니다.

저는 “문제 정의 -> 자료 탐색 -> 가설 설정 -> AI 피드백 -> 구조화 -> 재구성”의 학습 사이클을 반복하며, 단순히 개념을 아는 수준을 넘어 실제 설계와 문제 해결에 적용할 수 있는 수준까지 성장하겠습니다.

```
