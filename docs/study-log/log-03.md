### 2. 이번 타임의 학습 전략
- 이전에 바꾸기로 한 전략은 무엇이었고, 실행했는가?   
개념 학습보다 코드 구현에 집중해서 학습을 해보기로 했습니다.   
AI에게 관련 자료를 제공한 뒤 코드 구현에 집중해서 설명을 해달라고 했습니다.


- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
1. 집중할 하나의 필수개념을 정의하고, 내가 아는 것을 작성하며 내 상황을 체크한다.
2. 과제와 참고자료, 1번에서 작성한 것들을 모두 AI에 넣고, 코드 구현 위주로 설명해달라고 요청한다.
3. 코드를 읽고 우선 동작하도록 구현한다.
4. 코드가 작동을 안하면, 다시 처음으로(마지막 커밋 시점) 돌아가서 다시 구현해본다.

### 3. 전략 평가
- 효과적이었던 것과 그 이유   
코드를 보면서 시작하니까, 코드가 눈에 빠르게 익었습니다.   
덕분에 개념을 공부했을 때보다, 코드 문법에 대한 이해도가 높았던 것 같습니다.


- 비효과적이었던 것과 그 이유    
AI에게 코드 구현 위주로 먼저 설명 해달라고 했는데, 단순 나열식의 정보 설명이다보니 잘 이해되지 않았습니다.
또한, 개념 확립 전에 코드를 짜니까 막혔을 때 어디서 막힌건지 어떻게 해결해야하는 건지 파악할 수 없어 막막했습니다.
그러다보니 AI 의존도가 높아진 것 같습니다. 


- 막힌 것의 종류(1번)와 전략의 궁합은 어땠는가?   
막혔을 때마다 다시 푸니까, 코드 문법에 대해서는 확실히 빠르게 익혔습니다.   
코드 구현 방법에 대해서는 익숙해졌지만, 왜 이렇게 코드를 작성해야하는지에 대한 이해는 부족했습니다.
2단계의 전략대로 개념 확립을 한 후에, 3단계처럼 코드를 보는 방식이면 효과적일 것 같습니다.

### 5. 다음 타임에 바꿀 것
- 유지할 것과 그 이유   
코드 구현을 직접 하면서, 코드에 대한 문법을 익히는 방법은 유지하려 합니다.   
코드로 직접 써보니, AI가 설명했을 때보다 더 와닿고 이해가 쉬웠기 때문입니다.


- 바꿀 것과 그 이유   
코드 구현을 먼저하기 보다는 어느정도 최소한의 개념은 갖추고 시작하는 방향으로 수정하려고 합니다.
기둥이 되는 개념이 없고, 기준이 없으니 범위가 모호하고 더 복잡하게 느껴졌기 때문입니다.
