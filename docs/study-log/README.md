## 📖 학습법 v1 ~ v3

### 1️⃣ 학습법 v1

```text
요구사항이 주어줬을 때, 스스로 해볼 수 있는지 여부를 파악합니다.

복잡한 구현의 경우, 보통 먼저 AI를 사용하지 않고 먼저 글로 작성하여 실행 여부가 가능한지 파악했습니다.
그리고 실행 여부가 가능하면 코드를 작성했고,
실행 여부가 불가능하면 AI를 활용하여, 방향성을 물어보며 해답을 찾았습니다.

경험해 보지 못한 DB 연결 같은 경우, AI를 먼저 사용하여 큰 방향성을 물어보고 전체적인 흐름을 이해했습니다.
그리고 흐름 단계별로 AI에게 답과 답의 이유를 물어보며 학습했습니다.
```

### 2️⃣ 학습법 v2

```text
요구사항이 주어줬을 때, 스스로 해볼 수 있는지 여부를 파악합니다.

복잡한 구현의 경우, 보통 먼저 AI를 사용하지 않고 먼저 글로 작성하여 실행 여부가 가능한지 파악합니다. 이때 글로 작성하며 생각하는 시간을 30분으로 제한합니다.
그리고 실행 여부가 가능하면 코드를 작성하고,
실행 여부가 불가능하면 AI를 활용하여, 방향성을 물어보며 해답을 찾습니다.

경험해 보지 못한 DB 연결 같은 경우, AI를 먼저 사용하여 큰 방향성을 물어보고 전체적인 흐름을 이해합니다.
그리고 흐름 단계별로 AI에게 답과 비슷한 예제 코드를 물어보고 내 코드로 변환하여 학습합니다.
```

### 3️⃣ 학습법 v3

```text
복잡한 구현의 경우, 먼저 30분 동안 글로 작성하여 실행 여부가 가능한지 파악합니다.
그리고 실행 여부가 가능하면 코드를 작성하고,
실행 여부가 불가능하면 AI를 활용하여, 방향성을 물어보며 해답을 찾습니다.

무언가를 학습하는 경우, AI에게 질문하기 전에 5~10분 동안 “내 임시 멘탈 모델”을 먼저 작성합니다.
(새로운 개념인 경우, 구글링을 통해 기본 개념을 공부해서 내 임시 멘탈 모델을 만든다.)

*작성 형식
1. 내가 이미 알고 있는 것
2. 내가 예상하는 흐름
3. 내가 헷갈리는 지점 (1~3개만 쓰기, 많은 질문 X)
4. AI에게 검증받고 싶은 질문

위 4가지만 적고 AI에게 물어봅니다.
틀린 부분을 바로 고쳐주기보다, 내가 스스로 고칠 수 있게 질문해 주는 방식. (소크라테스 튜터 프롬프트 방식 사용)
AI에게 검증 받은 "수정된 멘탈 모델” 다시 쓰기
```
