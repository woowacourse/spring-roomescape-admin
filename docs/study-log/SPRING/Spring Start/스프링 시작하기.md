스프링은 자바를 더 빠르고, 쉽고, 안전하게 만들어줌. 스프링은 생산성, 단순성, 속도에 중점을 둠.

>"우리는 Spring 프레임워크와 함께 제공되는 많은 도구를 사용하며, 기본적으로 많은 솔루션을 사용할 수 있고 추가 코드를 작성하는 것에 대해 걱정할 필요가 없기 때문에 시간과 에너지를 절약할 수 있습니다."

## 개요
Spring은 Java 기반 엔터프라이즈 애플리케이션 개발을 쉽게 해주는 프레임워크임. 

스프링은 자바 언어 기반의 프레임워크  
자바 언어의 가장 큰 특징 -> 객체 지향 언어  
스프링은 객체 지향 언어가 가진 가장 강력한 특징을 살려내는 프레임워크  
스프링은 좋은 객제 지향 애플리케이션을 개발할 수 있게 도와주는 프레임워크

- 전통적인 엔터프라이즈 서버 환경
- 내장 서버 기반 단일 jar 실행
- 클라우드 환경
- 배치/독립 실행 애플리케이션

## 구조
Spring은 모듈 구조로 구성됨
- Core Container
	- 설정 모델
	- DI(Dependency Injection)
- 데이터 처리 (트랜잭션, 영속성)
- 웹 (Spring MVC, WebFlus)
- 메시징 등
