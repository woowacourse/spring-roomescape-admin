# 학습법 변천

### v1 (Level1 학습법)

```

1. 책을 읽을 때 처음부터 끝까지 읽는다.
- 아는 내용 부분도 읽는다.
- 이해가 잘 안되는 부분을 이해하는데 오랜 시간이 걸린다.

2. 따로 공부하려고 정리해 둔 개념들을 공부할 때, 쉬운 것부터 공부한다.
- 어려운 내용은 뒤로 미룬다.

3. 이론 공부만 해서 (코드 적용X) 실제로 코드에 녹여내지 못한다.
```

### v2

```
- 책을 사용하여 공부할 때, 아는 내용은 넘어간다
- 스스로 공부 후 이해가 잘 안되는 개념 학습에서는 ai를 사용한다.
    - 단, 무지성 코드 넘기기 금지
- 모르는 개념들이 나왔을때, 너무 깊은 내용까지 공부하려 하지말고 딱 필요한 부분만 공부한다.
    - 그후 하나씩 추가해나간다.
- 이론 공부 중 코드에 적용하기 어려운 상황이라면, ai의 도움을 받아 간단하게라도 사용해본다.
```

### v3

```
- 책을 사용하여 공부할 때, 아는 내용은 넘어간다
- 스스로 공부 후 이해가 잘 안되는 학습에서는 ai를 사용한다.
    - 단, 무지성 코드 넘기기 금지
- 모르는 개념들이 나왔을때, 너무 깊은 내용까지 공부하려 하지말고 딱 필요한 부분만 공부한다.
    - 그후 하나씩 추가해나간다.
- 이론 공부 중 코드에 적용하기 어려운 상황이라면, ai의 도움을 받아 간단하게라도 사용해본다.

- 인출 연습
    - 공부 후 5분 간 멍 때린다 (분산 모드 전환)
    - 공부 후 해당 개념에 대해 [백지 공부 or 다른 크루에서 설명하기]를 진행한다.
    - 막힌 부분은 기록해둔다.
- 약점 집중 훈련
    - 잘하는 것 말고 못하는 것부터 공부한다.
- ai에게 질문 시 정답을 요구하는 것이 아닌, 여러가지 방식을 도움받고,
    - 직접 적용해보며, 자신만의 답을 찾아간다.
    - 틀린 부분도 직접 적용해보며, 체화 시킨다. (당연하게 여기지 않기)
```
