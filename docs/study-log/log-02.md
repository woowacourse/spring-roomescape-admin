### Solo recall note

위치: docs/study-log/recall-NN.md
파일명: recall-01.md, recall-02.md, ... 순차
독자: 3개월 후의 나 (외부 발행 절대 금지)
빈도: 매 학습 세션 종료 시 1회
분량: 200~400자 (상한 엄수)
타이머: 10분 (그 이상 쓰지 않음)
형식: 일기체 평서문
검토: 작성 직후 다시 읽지 않음. 다음 세션 시작 시에만 봄

허용 (좌표 표시용):

- 어노테이션, 메서드 시그니처:
  `@Transactional(propagation = REQUIRES_NEW)`,
  `public void inner()`
- SQL 절 또는 쿼리 한 줄
- 인라인 코드 (백틱 한 줄)
- 짧은 메서드 한 토막 (중괄호 포함 5~8줄까지)

금지 (글 변질 신호):

- 실행 가능한 클래스/메서드 통째
- 노트 한 회차에 코드 블록 2개 이상
- 코드 블록의 합이 노트 본문(일기체) 보다 _길어짐_
- 코드에 `//`주석 또는 별도 설명 단락 붙임

## 3. 전략 평가

- 이 방식은 내가 스스로 **정보를 찾아**보고, 찾아본 결과를 내가 **정리하여 설명**해주어야 했다.
- jdbcTemplate의 경우 공식 문서가 도입 필요성과는 동떨어진 설명을 한다고 느껴졌다. 내용이 도입이 된 이유보다는 사용법에 철저히 맞춰져 있다고 느껴졌고 '공식 문서가 항상 최선은 아닌가?'라는 의문이 들었다.
- 학습법과는 별개로 학습 시간이 꽤 오래걸렸다. 오래 집중하려 하니, 오히려 집중력이 떨어지며 늘어지는 느낌이 들었다.

## 4. AI 피드백

### 4.1. 포모도로 적용

focus mode와 diffuse mode 구분이 필요하다.

```text
Focused Mode                    Diffuse Mode
─────────────                   ─────────────
  좁은 빔                          넓은 안개
  기존 신경 경로 따라감             멀리 떨어진 노드끼리 연결
  "JdbcTemplate.update()의          "어, 이거 결국
   파라미터 순서"                    Template Method 패턴이네?"
  의식적                            무의식적

   [의자에서]                      [샤워에서]
   [책상에서]                      [산책에서]
   [코드 위에서]                    [잠들기 직전에]
```

두 모드는 동시에 킬 수 없다. 책상 앞에 6시간 앉아 있으면 focused만 6시간 돌리는 것이다. 그 동안 diffuse는 한 번도 안 켜진다. 그래서 "오래 집중하려 하니 늘어지는" 느낌이 드는 것이며, 늘어지는 게 아니라 뇌가 다른 모드로 전환해달라고 신호 보내는 것으로 해석해야 한다.

```text
25분 focused (코드 작성, 문서 읽기)
   ↓
5분 강제 diffuse (이게 핵심)
   - 슬랙 보기 금지
   - 트위터 금지
   - 유튜브 금지
   - 다른 코드 보기 금지
   ↓
   허용: 창밖 보기, 물 마시기, 짧은 산책, 멍때리기
   ↓
   25분 focused
   ↓
   ...
   ↓
   4사이클 후 30분 긴 휴식 (이때 산책 추천)
```

### 4.2. Recall by Drawing

백엔드는 공간적 구조가 핵심이다. 요청이 어디로 가는지, 객체가 어디 살고 있는지, 트랜잭션이 어디서 시작되는지 이건 글보다 그림이 빠르다.

#### 4.2.1. 인지 부하 채널

```text
인간 뇌의 작업 기억:
┌───────────────────────────┐
│  Phonological loop        │ ← 글, 말 (지금 쓰는 거)
│  (언어 채널)               │
├───────────────────────────┤
│  Visuospatial sketchpad   │ ← 이걸 안 쓰고 있음
│  (공간/이미지 채널)        │
└───────────────────────────┘
```

두 채널은 독립적이다. 글로만 인출하면 한 채널만 쓰는 거고, 그림으로도 인출하면 두 채널을 다 쓰는 것이다.

Solo Recall Note 끝나고 추가로 5분만 더 시간을 내어 종이에 손으로 그려보는 것을 적용해 볼 것. 디지털 도구 금지.
