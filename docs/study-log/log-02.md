### 2. 이번 타임의 학습 전략

- 실제로 어떻게 학습했는지 디테일한 과정을 써보세요.
> 먼저, h2 환경 설정 및 테이블 스키마를 설정했습니다. 진행 도중 초기화 스키마를 설정하는 방법을 몰랐고, 이와 관련된 개념인
> "spring.sql.Init.data/schema-locations"을 리스트에 추가했습니다.
> 
> 예약 조회 기능 수정을 하는 도중, ResultSet을 이용하여 RowMap 구현체를 작성하게 되었습니다. 
> 여기서 getXXX가 스키마 타입과 정확히 일치해야 가져올 수 있다고 잘못 이해하여 String -> LocalDate/Time 수동 수행을
> 고민하는 문제가 발생했습니다.
> 이에 주변 크루에게 해당 문제를 공유했고, 유연한 타입 변환으로 Date로 자동 변환되는 사실을 알 수 있었습니다.
> 
> 파라미터 바인딩을 할 때 실수를 방지하고자 이름을 가지는 파라미터를 넘기기 위해 관련 솔루션을 검색을 통해 찾아봤습니다.
> 찾아본 결과 "NamedParameterJdbcTemplate"를 알게 되었고, 자세한 구현 사항은 최대한 공식 문서만을 활용하여 학습하였습니다.
