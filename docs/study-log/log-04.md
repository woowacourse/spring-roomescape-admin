### 2. 이번 타임의 학습 전략

이전 타임에 정한 "익숙한 영역에서도 30초 스케치 끼워 넣기" 전략을 적용했다.
4단계 자체는 1단계부터 Controller / Service / Repository / Domain / DTO를 분리해 작성했기 때문에 코드 수정은 없었고, 계층 분리가 잘 되었는지 확인만했다.
