# 학습법

## v1 (기존 학습법)
새로운 기술을 학습할 때 궁금증을 유발하는 키워드가 나오면 계속 파헤치는 방식으로 진행했습니다.
키워드는 세 가지로 분류했습니다. 모르는 것, 잊어버린 것, 알고 있지만 설명하지 못하는 것.

- 모르는 것: 관련 자료를 먼저 찾아보고, 얻은 지식을 AI에 컨텍스트로 제공하고 하브루타 방식으로 다졌습니다.
  - 하브루타 진행 방식 
    1. AI는 언제든 할루시네이션을 낼 수 있다는 전제로 시작합니다.
    2. 모르거나 궁금한 것, 이해가 안 되거나 모순된다고 느껴지는 부분을 정리해서 꼬리잡기 식으로 묻습니다. 
    3. 어느 정도 이해가 됐다 싶으면 공식 자료나 출처를 요구하고, AI가 제공하는 링크뿐만 아니라 직접 웹 검색을 통해 자료 소스로 들어가 크로스체크합니다.
    4. 만약 AI로부터 얻은 지식과 다른 부분이 있다면 공신력 있는 자료의 정보로 지식을 업데이트하고, 최종적으로 나만의 언어로 바꿔 정리합니다.
- 잊어버린 것: 해당 키워드가 나온 소스를 다시 찾아 여러 번 읽었습니다.
- 설명하지 못하는 것: 나만의 언어로 바꿔 글로 작성하거나 말로 내뱉었습니다. 공식 문서로 검증하고 예시를 들어 문장을 다듬었습니다.

## v2 (크루들의 피드백 반영)
학습법 v1의 키워드 탐구 방식은 유지하되, 피드백을 통해 Structure Thinking 개념을 추가했습니다.

바로 키워드부터 파고드는 게 아니라, 먼저 주제의 전체 흐름과 관계를 잡고 그 안에서 모르는 키워드를 찾는 순서로 바꿨습니다. 
깊게 파고드는 내용을 문서화하고 도구(Obsidian 등)를 활용해 흐름과 관계 중심으로 구조화합니다.

## v3 (AI 전문가 피드백 반영)
학습법 v2를 유지하되, 구조화 이후 단계와 학습 완료 기준을 추가했습니다.

새로운 주제를 만나면 먼저 전체 흐름과 관계를 머릿속에 그립니다.
"이게 왜 존재하는가? 어떤 문제를 해결하기 위해 만들어졌는가?"를
출발점으로 전체 흐름과 관계를 그립니다. (First Principles)

큰 그림이 잡히면 그 안에서 모르는 키워드를 분류하고, v1의 하브루타 방식으로 다집니다.
정리된 내용을 다시 전체 흐름에 반영하면서 구조화를 완성합니다.

구조화가 끝나면 아래 세 단계를 추가로 진행합니다.

- 연결: 배운 개념과 기존에 알던 지식 사이의 관계를 찾아봅니다.
  비슷한 것, 반대되는 것, 상위/하위 개념 모두 해당됩니다.
  다만 해당되지 않을 때는 억지로 만들지 않습니다.
- 재현 (Feynman Technique): 정리한 걸 보지 않은 상태에서,
  이 개념을 처음 듣는 사람에게 설명하듯 표현해봅니다.
  막히는 지점이 아직 모르는 부분입니다. 매끄럽게 설명될 때까지 반복합니다.
- 문제 연결: 개념과 관련되어 생길 수 있는 문제들을 생각해봅니다.
  실제 코드나 설계에서 어떤 상황에 마주칠 수 있는지 연결해봅니다.

### 학습 완료 기준
학습 완료 기준은 세 가지입니다.

안 보고 꺼낼 수 있을 것, 
실제 문제와 연결할 수 있을 것,
그리고 정리한 개념을 실제 코드나 설계에 적용해보는 것. 

세 가지가 모두 충족하는 상태를 학습 완료로 봅니다.
