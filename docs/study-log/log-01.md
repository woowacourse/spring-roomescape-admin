### 4. AI 피드백

아래는 AI에게 학습법과 학습 내용 전문과 함께 보내고 받은 피드백입니다.

---

이번 학습은 좋았습니다. **실제 코드에서 막힌 문제를 출발점으로 삼고, 공식문서를 확인한 뒤 바로 코드에 적용한 점**이 특히 좋습니다.

다만 질문을 조금 더 정확하게 바꾸면 학습 효율이 좋아집니다.

기존 질문:

```text
AtomicLong을 Long으로 어떻게 변환하는가?
```

더 좋은 질문:

```text
AtomicLong에서 현재 값을 꺼내 Reservation의 id로 넣으려면 어떤 메서드를 써야 하는가?
```

이번 상황에서는 단순히 값을 꺼내는 것이 아니라, **현재 id를 사용하고 다음 id를 위해 1 증가시켜야 하므로** `getAndIncrement()`를 사용한 선택이 적절합니다.

다음부터는 공식문서 전체를 정리하기보다, 지금 문제와 관련된 메서드만 비교해보시면 좋겠습니다.

예를 들면 이번에는 아래 3개만 비교해도 충분했습니다.

```text
get()
longValue()
getAndIncrement()
```

추가로, 코드에 적용하기 전에 아주 작은 실험을 해보면 이해가 더 빨라집니다.

```Java
AtomicLong index = new AtomicLong(1);

System.out.println(index.get());             // 1
System.out.println(index.getAndIncrement()); // 1
System.out.println(index.get());             // 2
```

### 5. 다음 타임에 바꿀 것

#### 유지할 것과 그 이유

- 학습한 내용에 대해서 짧게 학습하고 정리한 뒤, 정리한 내용을 다시 되돌아보면서 의식적으로 궁금한 점을 찾아낸다.
  - 너무 깊거나 주변 다른 개념까지 학습하려고 하면, 시간도 오래 걸리고 불필요한 개념까지 학습하게 되는 경향이 있는 것 같습니다.


#### 바꿀 것과 그 이유

- 공식문서를 직접 찾아보고 번역하는 대신, AI에게 공식문서 또는 신뢰할만한 근거를 함께 달라고 질문한다.
  - 직접 찾고 번역하는데 시간이 오래 걸리고, 공식문서에는 원하는 내용이 존재하지 않을 수 있어서 시간이 너무 많이 걸리게 되었습니다.
